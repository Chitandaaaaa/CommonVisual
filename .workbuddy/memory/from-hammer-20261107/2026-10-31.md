## 需求：页内「逐动作解说」面板（讨论定稿，尚未动代码）

### 要做什么

每个原语页页头的「时序」按钮弹出的面板，从单一内容改成 **3 个 tab**（**注：第二轮修订后砍掉「配置原文」，只剩 2 个 tab，见下文**）：

1. **时序**（现有，不动）
2. **配置原文** —— `fetch('assets/scenes/<id>.js')` 显示源码，带行号，原封不动
3. **逐动作解说** —— 从画面出发的中文解说（本次重点）

### 解说文的硬要求（用户逐条定下）

- **每动一下 = 一个小节**，用二级编号（`3.5`）
- **同一时刻发生的动作分开写**（按元素拆，不合并）
- 每节三要素：**是什么 · 动作是什么 · 结果是什么**；机制不在这里解释
- **起止时间进列表**（每行带 `1.20–2.70s`，不是塞在括号里）
- **静止帧单独成节，保留**，并参与高亮
- 不写：文案、几何数字、内部钩子（overlay / wireStyle / preAt / onBuild）
- 语言必须**标准化**：reduce / allreduce / reducescatter / alltoall 复用同一套名词与句式

### 名词表 v1（已给用户确认方向）

- 卡片按槽数命名：**单槽卡 / 四槽卡 / 双排卡 / 计算态卡**（卡宽恒定，槽多了不会变宽）
- 零件：卡体 / 标题条 / 角标 / 槽
- 槽三态：**空格 / 接收位 / 数据块**（槽=位置，块=数据）
- 连线与运动体：弧线 / 单体包 / 整份包 / 残影
- 动作 12 个：变暗 / 复原 / 显形 / 转接收位 / 点亮 / 起飞 / 飞行 / 抵达 / 淡出 / 余辉 / 落位 / 弹跳
- 预留 5 个（其他页用）：第二排 / 长高 / 计算框 / 累加器 / 融合
- 两个反直觉点必须在名词表里说清：**落位不是渐变换色**（接收位当场消失、数据块弹出）；
  **余辉不是变灰**（保留数据色，只降到 40%）

### 播放联动高亮（用户新提，同样要做）

- 动画播放到某一步 → 列表对应那一行高亮；拖进度条、单步、静止帧都要跟
- 前提：解说的起止时间与动画**共用同一份编译时间轴**，不能各算一份
- 坑：齿轮面板改倍数 / 全局播放速度后，区间必须重算，否则高亮漂移
- 自动滚动只在行不在视野时做，且用户手动滚动后暂停跟随

### 关键发现（审计算法核对过实现）
- 探针硬编码路径不只是端口问题：`import('file://' + path)` 在 Windows 非法，必须 `pathToFileURL`。
- v2 reduce 的 t0 预留空槽是「接收中」态（cast.set active：#f3eeff 无虚线），V4 只认 idle 态所以误报——allreduce 的空槽从不被 set 所以没事。
- allreduce 开场字幕末尾带「逐段待相加」，字幕正则锚点法天然会撞上；这就是 3.42/3.43 待时序定稿后改 win 现算的原因。
- **W1 跨机器差 1px**：index 节点卡 mac 实测 282×64、Windows（中文行高不同）282×63——像素级断言有机器依赖，待处理区已登记，容忍度待用户定。
- testing.html 曾有 25+ 处脚本列写错（全写 gather.mjs），本轮随重排一并勘误。
