### 连线笔画收编（2026-11-03 · 已提交 8a78bf0）

**根因**：连线样式没有唯一控制者。`payload.link()` 出生时给一套默认（2 / `8 7` / TONE.wire）
但没人当权威；真正样式在 move / sum / split 的 render 里逐帧 `setAttribute` 写死字符串；
CSS 的 `.wire` 只管过渡时长；`spec.js` 的 `04-wire` 只有一个 `wireFade`，**线宽虚线根本没进表**。

**落地方案**：
- `spec.js` 的 `04-wire` 从 1 键扩到 **12 键**（含 wireFade），分四组：过渡 / 线宽 / 虚线 / 透明度。
  线宽 `wireW` 2、`wireWLit` 2.6、`wireWGlow` 1.8、`wireWMuted` 1.4（全换闲置专用）；
  虚线 `wireDashOn/Off` 8/7、`wireDashLitOn` 9（点亮间隔仍复用 wireDashOff）；
  透明度 `wireOpIdle` 1、`wireGlowOp` .42、`wireRestOp` .75（收轮）、`wireDoneOp` .26（收场）。
- `payload.js` 新增 **`CV.wire.paint(path, state, color, muted)`**，五态
  `idle / lit / glow / rest / done` 一张表；配套 `CV.wire.arrow(markerEl, color)`（箭头随色）。
  `payload.link()` 建完 path 就调一次 `paint(p,'idle')`。
- 全部 14 处 `setAttribute` 改调（move 的 render + ringWires + alltoall、sum 的两处、split 一处）。
- all-to-all 的"细一档"改由 `wireWMuted` 表达（宽度 1.4 保留），**虚线回全站 `8 7`** ——
  原来它 6 6 是唯一例外，用例 5.44/5.45 本来就在记录这个分叉，现已改成验证统一。
- 外观页签 **93 → 104 行**（探针 `tools/probes/ledger.mjs` 的 6.1/6.2/6.5/6.6 断言同步）。
