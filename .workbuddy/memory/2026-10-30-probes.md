# 2026-10-30 · v2 断言探针全套实现（tools/probes/v2/）

为 v2 重构写验收探针的会话（另一条会话在写 v2 页面代码）。**交付物：83 条用例全部实现成
可自动运行的断言，在旧页（仓库根 12 个 html）上自检通过，v2 页面就位后直接跑绿。**

## 交付了什么
- `tools/probes/v2/_common.mjs`：第 2 组全站通用 15 条（2.1–2.15）+ 蓝图 §09 的 V1–V9，
  做成 `commonChecks(pg, cfg)` 供 8 原语页复用（每页传：有无齿轮 / 边列表 / keepCards /
  空闲线样式等）。v2 才跑 2.15（registry 契约）。
- 8 个原语页探针（gather 3.1–3.7 … alltoall 3.48–3.53，名字里带 testing.html 编号），
  4 个静态页探针（index 4.1–4.4+2.14 / layout 4.5–4.7 / algorithms 4.8–4.9 / anatomy 4.10–4.12+2.11）。
- 旧页没有 getCh 的四页（reduce/allreduce/reducescatter/alltoall）带一份「旧页实测刻度表」
  （_common 的 OLD），仅自检期使用；v2 挂 getCh 后自动切现算。

## 怎么跑
- v2 页面：`node tools/verify.mjs v2/gather … --no-shot`（页面 v2/<p>.html ↔ 探针 probes/v2/<p>.mjs 自动配对）。
- 旧页自检：临时把 v2/*.mjs 复制到 tools/probes/（_common.mjs 也复制），跑完删，别提交。
- 实测：12 页 `--no-shot` 约 2 分 20 秒，两轮 12/12 全绿。

## 量出来的口径修正（都已写回 testing.html 红条 / blueprint §09 勘误）
- **3.30 allgather**：不是「同时只有一条边在动」——每轮四条边同时高亮、轮间串行。
- **3.35 allreduce**：初始态是每卡一整份 ABCD，不是「各 1 块」（那是 allgather 的起点）。
- **3.37 allreduce**：横向轮后每卡 4 块全是 2 份 Σᴀ²，不是「各 2 块」。
- 4.1 / 4.5 / 4.7 / 4.12：index 顺序=树序（不比对照表序）；对照表行格数 1–4 随数据形状；
  index 与 layout 只比集合不比顺序；anatomy 是单章视图、07 动态无 tab。
- blueprint §09：V5 角标（角色 28/30×18、文字 36×18）、V4（#f3eeff=接收中）、
  W1（282×64）、W5（28×28 rx7 字11.5）、W7（无 text-transform）。

## 探针的坑（新会话写探针前先看）
- 同卡多排槽位先按 y 再按 x 排，否则上下排交错；t0 快照前必须 seek(0)（页面自动播放）。
- allreduce/rs 块色是 CV.mix 的 rgb() 输出，比色要归一；reduce 系第二排空槽伸出卡底 ~6px，
  槽→卡归属用「中心落卡内 + 底边 12px 容差」。
- `pg.goto` 只吃绝对 URL；anatomy 目录点击=切节（单章视图），不是滚动锚点。
- **工具 bug（未修，属边界）**：`tools/probe.mjs` 对静态页（index/layout/algorithms/anatomy）
  会崩——它无条件 `api.controls.setPlaying(false)` 而静态页没有 CV.lastMount。
  最小修法：evaluate 里先判 `api` 再 seek。静态页真值现在用 verify.mjs 跑探针量。
