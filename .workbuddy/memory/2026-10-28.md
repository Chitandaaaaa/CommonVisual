## allgather 虚线/箭头颜色 bug（用户截图报的）
- 症状：一条灰色的虚线，末端箭头却是青色（别的段的颜色）。根因有两个，都在 allgather.js：
  1. **同一条边被画了 4 条 path**：`wires[q + '_' + f.from]` 按「轮次+源」建 key，环上同一条边每轮都新建一条线叠上去。同一时刻只有一轮在飞（下层染了色），但上层 q 更大的那条还是灰的 → 灰线压住彩线。改成 `wires['e' + i]`，按**边**建（4 条），颜色由「这条边此刻跑到第几轮」决定（取最后一个 `sec >= f.start` 的轮次）。
  2. **marker 按字母建、被多条线共享**：`'ah' + f.letter` 只有 4 个，同一条边每轮携带的字母不同 → 字母跑到别的边上，箭头颜色被那条边覆盖。改成按**边**建 `'ae' + i`。
- 同类问题在 **reducescatter**：marker 按轮次建 `'ars' + rd.q`，同一轮 4 条边发的段不同、`colorFor` 混色也不同，共用 marker → 4 个箭头被最后一条染成一个色。改成 `'ars' + q + '_' + r`（每条边一个）。其余 6 页 marker 天然一对一（gather/scatter/broadcast/reduce 按 rank 建、allreduce 递增 id、alltoall 无箭头）。
- **primitive.js 补清 marker**：`buildStage` 原来只清 6 个 layer，defs 从不清 → 每次 rebuild（resize/改参数/换几何）堆出第二套同名 id，`url(#…)` 解析到第一个，页面拿到新元素、线却指着旧的。现在只移除 `defs marker`（**不能清 defs.innerHTML**，html 里那套 `gGrid` 网格 pattern 在里面），实测 reload 3 次 markers 恒为 8、gGrid 恒为 1。
- 验证：8 页 × 5 个时间点，「每条 wire 的 stroke === 它 marker 的 fill」全部成立（140 次采样 0 不符）、无重复 marker id、零异常、duration 一个没变（gather 仍 13150）。
- 探针坑：`Page.captureScreenshot` 在旧实例上会对多个 target 返回同一帧缓存，跨实例重截 md5 才一致 —— 判断「截的是不是这一页」以 evaluate 到的 `location.href`/`h1` 为准，别信图。
