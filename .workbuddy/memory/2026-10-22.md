## CommonVisual 分布式通信原语可视化 · Gather 页面设计

**项目**：从零搭建的 Web 可视化项目，素材来自 `分布式通信原语详解.md`（NCCL 8 种集合通信原语）。
首个原语选定 **Gather（收集）**。

**产出文件**
- `index.html` — 单页结构（Hero / 指标卡 / 前后对照 / 动态演示 / 步骤拆解 / 代码 / 原语对比表）
- `assets/style.css` — 浅色主题，CSS 变量驱动，响应式断点 1080 / 780 / 520
- `assets/app.js` — 数据模型 + SVG 舞台构建 + 时间轴状态机 + 代码高亮

**关键技术决策**
- **舞台用 SVG 而非 DOM**：连线需要精确的三次贝塞尔路径，`getPointAtLength()` 让数据包能沿路径运动。
- **双布局几何**（`GEO_WIDE` / `GEO_TALL`）：宽屏 dst 在左、源卡竖排右，连线经中间竖直总线汇聚；
  窄屏（<780px）dst 在上、源卡横排下，链路自下向上扇入。`syncLayout()` 在 resize 时重建舞台并重绘。
- **时间轴归一化 0→1**：`T` 常量定义各阶段区间（init / alloc / 3 段传输 / done），
  `paint(t)` 是纯函数式渲染，拖动进度条即回放任意时刻，天然支持 scrub。
- **代码高亮用单次正则扫描**（`new RegExp` 而非字面量，因为关键词表要插值）：
  字符串 / 注释 / 数字 / 关键字 / 函数名一次匹配，避免二次 replace 破坏已生成的 span。
- **坐标系象限图按原文档对齐**：Gather 在「全体发 × 1 人收」，Scatter 在「1 个人发 × 1 人收」。

**内容要点**
- PyTorch `dist.gather` 需要仅 dst 传 `gather_list`，其余传 `None`。
- **NCCL 后端不支持 `gather`**（官方后端能力表标记为 ✘），GPU 场景用 `all_gather` 取切片或 `gather_object` 替代；
  页面给出了点对点手写的等价实现。
- Gather 是复制语义：源卡数据不被搬走，只有 dst 缓冲区膨胀 N 倍 —— 与 Reduce（汇总压缩）的分水岭。

**验证方式（可复用）**
- jsdom 无头测试：DOM 构建产物计数 + 时间轴各关键点状态断言 + 交互回归。
- 真实浏览器：系统 Chrome `--headless=new --remote-debugging-port` + CDP（ws 直连）截图与运行时检查。
  注意：沙箱内 `npm i agent-browser` 的 Chromium 下载会被代理超时阻塞，改用系统 Chrome 更可靠。
- 注意 Bash 调用结束会回收后台进程，静态服务与 Chrome 必须写在同一次调用脚本里。
