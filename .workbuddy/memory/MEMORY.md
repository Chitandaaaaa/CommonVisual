## gallery.html（当前主战场）
- 结构：`SEC(parent, 编号, 名称, 说明)` 先插 `h3.sec` 再插 `.note` 再插 `.grid` —— **取样片网格必须循环找 `.grid`**，`h3.nextElementSibling` 会拿到说明条。
- **样片必须 1:1**：`.tile svg { width:100% }` 会把小件放大到列宽。小件一律自建 tile + 内联 `width:Npx`（`MONO` / `strip` / `pktTile` 三种壳），宽画布挂 `.grid.wide`（`max-width:800px` 封顶）。
- 画法函数：`block()`（2.x 数据块/分片/规约/空/接收/置灰）、`slotRow()`、`badge()`、`cardG()`（1.x 卡片，300×170 或 h:203）、`packetG()`（5.x 数据包）、`wireCard()`（4.x 用真卡当端点）、`SEC` 之外的 `LOOP()` 驱动第二部分动画。
- 说明条同时写进 `h3` 的 `<small>` 和 `.note`，同一句话一屏出现两遍 —— 待用户定夺是否删其一。
- 画谱不引 `assets/`，数值全部照抄两份文档；所以**改文档数值后要手动同步画谱**。

## 几何判据（代码里看不出来、跨会话仍成立）
- **空白区中线 = 卡顶 + 95**：标题栏 36 + 空白区 118 ÷ 2（1.1.5：空白区高 118、下沿距卡底 16）；数据格行顶 72 + 块高 46 → 中心也是 95。4.1/4.3/4.6 的连线 y 都按卡顶 + 95 算（曾误算成 103，整组偏高 8px）。
- 4.x 卡与卡的空当（横 180 / 纵 160）**文档没定义**，取自 v1 舞台卡距，只为比例像真页。
- **Σ 上下标走 em 语义**：`dy` 的 em 按**该 tspan 自身**的 font-size 换算。46 基准下 下标 9.3 字 ×0.34 = 3.16、上标 7.8 字 ×1.28 = 9.98（相对下标基线，净上移 6.82）。文档 2.2.2 / 2.3.2 写的 5.1 / 19.2 是把 em 按父级 15 换算，照它画上标会飞出色块顶 —— **已提报，等用户裁**。画谱用 `const SCRIPT = { sub: .34, sup: 1.28 }` 一处定义。
- 弧线（4.1.1）：贝塞尔控制点沿**主轴**摆，两端等高时四点共线会退化成直线 —— 样片里两端必须有高差。
- 箭头（4.1.2）：平头小三角，`viewBox 0 0 8 8`、`refX 8`，size = 箭头大小（11 / 14.3 / 9.9 = 5.5 × 线宽）。
- 4.7 余辉仍是**虚线 8 7**（复用 4.1.1 的线型），只把宽度降到 1.8、不透明度 0.42。

## 组件判据
- **参数 = 能被独立赋值的自由度**：凡「A 必然等于 B」或「A 由内容算出来」就不是参数，写进上一级描述或删掉。
- **复用行只写差异，读者判断不了构成** —— 画谱照「复用」画之前先回被复用节看实体（5.2.4 复用 5.1.3 的「拖尾方块」就被当成过整组）。
- 送出的那格写「空」，不是「接收中」；槽位三态（空/接收中/有数据）语义别反。
- 通信前每卡是**一整份 [A B C D]**；「各卡一片」只是 all-gather 的起点。
- all-reduce 份数翻倍（1→2→4），不是加一；reduce-scatter 用 recursive halving，不用 ring。

## 技术坑（SVG / 浏览器）
- SVG 没有 offsetWidth（用 getBoundingClientRect）；`<circle>` 不写 fill 是黑的；CSS font-size 会盖掉 SVG 属性。
- **marker 的 id 是全局共享的**：一条线一个 marker，别共用，否则箭头颜色互相覆盖。
- 逐帧写 opacity 别挂 `transition`（会被反复重启）；多段时间轴用秒写。
- `filter: feGaussianBlur + feFuncA(slope)` 接在色块上会把**本体** alpha 乘掉（拖尾曾因此只剩 0.077）——要「外面补软影」就用 `feDropShadow`。
- CSS `drop-shadow(…, blur)` 的 blur 是 2× 高斯标准差，所以 `feDropShadow` 的 stdDeviation 取 `blur/2` 才对得上文档里的「投影模糊 12 / 滤镜模糊 4」。
- 位移＋缩放要 `transformBox='view-box'; transformOrigin='0 0'`，别叠两层 transform。
