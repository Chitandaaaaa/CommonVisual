# ③ 组件 · 名词与零件规格

> 本篇定义舞台上的**零件**：每个物件叫什么、由什么构成、有哪几个状态、几何怎么算。零件只有状态，没有时间——何时进入哪个状态是⑥过程的事；一切尺寸、颜色、时长引④参数键，本篇不出现裸值（几何公式除外，公式里的字母量引④ `geo` 组）。
>
> 实现转录：`assets/prim/`（几何·曲线）+ `assets/parts/`（cast 卡 / payload 包线 / beat 曲线）+ `docs/visual.html`（1:1 量尺视图）。

承纲领：复用唯一实现 · 数据行为分离。

---

## 1. 物件名词总表

| 名词 | 构成与定义 | 注意 |
|---|---|---|
| 参与者卡（rank 卡） | 白底圆角矩形 + 顶部彩色标题条（写 `rank N`）+ 右端角标 | 卡宽**恒定**，槽多不变宽，只有高度会变 |
| 标题条 | 卡顶色带，底色 = 该卡 rank 对应数据色 | 高度 `hdr` 组键 |
| 角标（badge） | 标题条右端小胶囊：`src` / `dst` 是角色，`1/4` / `4 段` 是进度 | 角色与进度不混用 |
| 目标卡态 | 接收方卡的边框发亮（描边高亮） | 只有 gather/scatter/reduce 家族的 rank 0 |
| 槽位排（row） | 卡内一排 n 个槽，居中；单排卡 1 排，双排卡 2 排 | 排数变化见「长高」 |
| 槽（slot） | 卡内一个方形**位置** | 槽是位置，块是数据；槽可以空着 |
| 空格 | 槽的空态：浅灰底（`toneSlotBg`）+ 灰虚线框，无字 | 看得见但没数据 |
| 接收位 | 槽的待收态：紫底（`toneSlotHot`）+ 紫实线框 + 居中 `···` | 只出现在接收方 |
| 数据块 | 槽的数据态：实色底（rank 色）+ 白字母 | A 紫 / B 青 / C 绿 / D 橙（④ `01-color`） |
| 分片块 | 数据块 + 右下角小下标（第几片） | all-to-all 专用 |
| Σ 块 | 累加块：`Σ` + 下标列字母 + 份数上标（Σ²、Σ⁴） | 份数每次相加 +1（all-reduce 折进翻倍语义见②） |
| 计算框 | 双排卡中间插一层，写 `sum · avg · max · min` | 算完即退回双排卡 |
| 弧线 | 两卡间虚线弧（S 形）+ 末端小平头箭头 | gather/scatter/broadcast/reduce 家族用 |
| 直连 | 两卡间双向直线，无箭头 | allgather 环边 / allreduce / reducescatter / all-to-all 用 |
| 数据包 | 运动体：单体包（装 1 块）/ 整份包（并排 4 块） | 包身 = 数据块的迷你版 |
| 残影（拖尾） | 包身后两层逐渐缩小的副本，越远越淡 | 永远在来路上 |
| 图例 | 色块 + 字母的数据对照表 | 位置由版式键给出 |

## 2. 状态机（每零件的全集状态）

### 2.1 槽

```
不可见 ──显形──▶ 空格 ──转接收位──▶ 接收位 ──落位──▶ 数据块（分片块 / Σ 块为变体）
                    ▲                  │
                    └──────复原────────┘（收场逐块撤回空格）
```

- 显形：从不可见淡入为空格或接收位，时长 `revealDur`。显形的是**位置**，不是数据。
- 接收位只在「包在飞的那段」存在：新增的第二排空位一律先显形为**空格**，对应包起飞才转接收位（收场同理先撤回空格）。
- 落位：接收位当场变数据块，**瞬时**，不是渐变换色；块变色过渡本身为 `slotCross`（仅当同一槽前后都是块时使用，如 Σ 浓度加深）。

### 2.2 连线（唯一画笔语义，五态）

| 态 | 名 | 外观 | 键 |
|---|---|---|---|
| 1 | 闲置 idle | 灰（`toneWire`）虚线 | `wireW` / `wireDashOn·Off` / `wireOpIdle`；全换页闲置细一档 `wireWMuted` |
| 2 | 点亮 lit | 数据色、加粗、箭头同色 | `wireWLit` / `wireDashLitOn`；过渡 `wireFade` |
| 3 | 余辉 glow | 降到 `wireGlowOp` 保留数据色 | `wireWGlow`；持续 = `packDur × trailRatio`，随后回灰 |
| 4 | 收轮 rest | 退灰但比闲置亮（「这条用过一次」） | `wireRestOp` |
| 5 | 收尾 done | 全灰弱化（终态） | `wireDoneOp` |

点亮是渐变（`wireFade`），余辉**不是变灰**。

### 2.3 数据包

- 起飞：包在起点出现并渐显，渐显占行程前 `takeoffFade`（比例）。
- 飞行：沿路径缓入缓出（非匀速），时长 `packDur`，两层残影跟随（间距 `trailDist`，浓度 `trailScale`）。
- 淡出：抵达后不透明度线性 → 0，时长 `packFade`；包是被目标「吃进去」，不是飞过头。

### 2.4 卡

| 态 | 定义 | 键 |
|---|---|---|
| 正常 | 不透明度 100% | —— |
| 变暗 | 卡整体不透明度 → 60%（编排定数，见①§9） | 时长 `dimDur`；只有 gather 用 |
| 长高 | 顶边钉死、只往下长一层（腾第二排 `cardDur` / 腾计算层 `growDur`） | 开场只做一次，收场才收回 |
| 计算态 | 双排卡 + 计算框 | 算完即退 |
| 收回 | 双排退回单排 | `cardDur` |

## 3. 几何公式（本篇唯一允许的数字：公式字母量）

### 3.1 弧线 · S 形（全站唯一曲率）

控制点沿**主轴**摆，不沿弦摆：横长的线水平进/水平出，纵长的线垂直进/垂直出；线从卡缘平着拉出去、中途再弯。

```
给起点 (sx,sy) 终点 (tx,ty)，k = arcK：
|dx| ≥ |dy|（横长）: C (sx+dx·k, sy) (tx−dx·k, ty)
纵长             : C (sx, sy+dy·k) (tx, ty−dy·k)
```

双向互换的两条车道：同型曲线整体沿**法向**平移 `off`（横向车道 `humpH`、纵向 `humpV`），端点随车道平移（包的起终点跟着走）。

### 3.2 弹跳曲线（全站唯一一份）

三停点 + 贝塞尔缓动，CSS keyframes 与 JS 逐帧采样同源生成：

```
stops: (t=0,   scale 0.35, opacity 0)
       (t=0.55, scale 1.16, opacity 1)   ← 过冲顶点
       (t=1,   scale 1.00, opacity 1)
ease:  cubic-bezier(0.2, 0.9, 0.3, 1.45)
```

### 3.3 版式系统

| 版面 | 布局 | 用于 |
|---|---|---|
| `col34` | 左 1 张卡 + 右 3 张竖排 | gather / scatter / broadcast / reduce |
| `grid` | 2×2 四张卡 | allgather / allreduce / reducescatter / all-to-all |

- 骨架两套：桌面 `dt*` 组键 / 窄屏 `nr*` 组键，断点 860px（⑦）。
- 卡位坐标由版式键给出（`c34*` / `gr*` 组）；图例位置 `Ly` 键。
- 槽位几何：槽宽高 `slotSw·Sh`、槽距 `slotGap`、卡头 `hdr`、字号 `TitleFs·BadgeFs`。
- 连线端点：弧线从源卡左缘 → 目标卡右缘（col34）；落点按槽位分布；grid 直连走卡缘中点，对角线走直线（前提：每步最多一条对角线在动，⑥顺序律保证）。

## 4. 组件边界（判定条款）

1. 组件不知道任何原语——没有「gather 卡」这种东西，只有「col34 版面里 rank 0 的四槽卡」。
2. 组件不知道时间——不持定时器，不问进度；状态切换由⑥⑦驱动。
3. 同一能力全站一份：弹跳曲线一份、弧线公式一份、画笔五态一份；任何第二份副本即违规。
