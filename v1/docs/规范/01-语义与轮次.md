# ② 语义与轮次 · 8 页的通信事实

> 本篇定义 8 个原语页的**静态事实**：通信前谁持有什么、通信后谁持有什么、分几轮、每轮谁发给谁。纯数据声明，不提任何动画（怎么动是⑥的事）、不解释算法原理。
>
> 实现转录：`assets/registry.js`（pre/post/verbs）+ `assets/rounds.js`（轮次/边/锚点）。改事实先改本篇。

承纲领：唯一事实 · 数据行为分离。

---

## 1. 数据字典

| 名词 | 定义 |
|---|---|
| 段 | 一份数据的四等分之一，用字母 A / B / C / D 标识 |
| 整份 | 4 段的全集（A B C D）；四张卡各持一份时形状相同、数值不同 |
| 分片 | 段再按目的地切片，记 `A:0`（A 的第 0 片），下标 0–3 |
| Σ 块 | 折进 2 份以上数据的累加结果，记 Σ + 份数上标（Σ²、Σ⁴） |
| rank | 参与者编号 0–3，固定 4 张卡；rank 0 在左/左上 |

**通用不变式**（8 页共用）：

- N = 4；一整份 = 4 段。
- 每页动画开始 = pre 态；结束 = post 态；post 是动画终态的唯一事实来源，页面与探针只读它。
- 单向依赖链：allreduce = reducescatter + allgather（reduce-scatter 是 all-reduce 的前半段）；scatter ↔ gather 互为镜像。

## 2. 消耗 / 复制语义（谁的块在发送后消失）

| 语义 | 页 | 表现（送出方） | 接收方 |
|---|---|---|---|
| 复制 | gather | 源卡**保留**原块，整卡变暗再复原 | 新增该段 |
| 复制 | broadcast | 源卡**保留**整份（不变暗不交空） | 4 格同时获得整份 |
| 复制 | allgather | 源卡**保留**自己段 | 按环逐轮收齐 |
| 消耗 | scatter | 源卡该格**立刻交空** | 新增该段 |
| 消耗 | reduce | 源卡整份**交空清空** | 折进累加器 |
| 互换 | allreduce / reducescatter | 交出互换段（消耗），同时收对端段 | 折进 / 留一半 |
| 互换 | alltoall | 上排对应片交空 | 下排收对端片 |

## 3. 逐页事实（8 页）

每页固定给出：名称、方向、一句话语义、前后态、行为集（verbs，对应⑥的过程模板）、轮次口径（公式 / 模式 / 每轮边 / 轮内相 / 验证锚点）。

### 3.1 gather · 收集（N → 1）

- 语义：拼接——三段汇入 rank 0 拼成整份；源卡保留原段。
- pre：`r0=[A]` `r1=[B]` `r2=[C]` `r3=[D]`
- post：`r0=[A,B,C,D]（拼成 4 段）` `r1=[B]` `r2=[C]` `r3=[D]`
- 行为集：move
- 轮次：公式 **N−1**（3 轮）；模式：链式，第 k 轮卡 k 把自己那段发给卡 0。
  - 第 1 轮边 `1→0`；第 2 轮边 `2→0`；第 3 轮边 `3→0`
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（单颗）→ 轮歇
  - 锚点：`r1.e` `r2.e` `r3.e` `tail.e`

### 3.2 scatter · 分散（1 → N）

- 语义：拆分——整份拆成四片各发一人；源卡留下第 1 段。
- pre：`r0=[A,B,C,D]` 其余空
- post：`r0=[A]（留下第 1 段）` `r1=[B]` `r2=[C]` `r3=[D]`
- 行为集：move、split
- 轮次：公式 **N−1**；模式：链式，第 k 轮卡 0 把第 k 段发给卡 k（gather 的镜像）。
  - 第 1 轮边 `0→1`；第 2 轮边 `0→2`；第 3 轮边 `0→3`
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（单颗）→ 轮歇
  - 锚点：`r1.e` `r2.e` `r3.e` `tail.e`

### 3.3 broadcast · 广播（1 → N）

- 语义：复制——整份复制给三人，人人拿到整份副本；源卡保留。
- pre：`r0=[A,B,C,D]` 其余空
- post：`r0=[A,B,C,D]` `r1=[A,B,C,D]` `r2=[A,B,C,D]` `r3=[A,B,C,D]`
- 行为集：copy
- 轮次：公式 **N−1**；模式：逐个直发，第 k 轮卡 0 把整份复制给卡 k。
  - 第 1 轮边 `0→1`；第 2 轮边 `0→2`；第 3 轮边 `0→3`
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（整包）→ 轮歇
  - 锚点：`r1.e` `r2.e` `r3.e` `tail.e`

### 3.4 allgather · 全收集（N → N）

- 语义：各自拼齐全份——四张卡都拿到完整一份。
- pre：`r0=[A]` `r1=[B]` `r2=[C]` `r3=[D]`
- post：四张卡都是 `[A,B,C,D]`
- 行为集：move
- 轮次：公式 **N−1**（3 轮）；模式：环形，每轮每卡把持有的段顺时针发给下家（环 0→1→3→2），三轮人人齐整份。
  - 每轮边：`0→1` `1→3` `3→2` `2→0`（三轮复用同 4 条边）
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（齐弹）→ 轮歇
  - 锚点：`r1.e` `r2.e` `r3.e` `tail.e`

### 3.5 reduce · 归约（N → 1）

- 语义：相加——四份逐段相加；只有 rank 0 拿到；**源卡送完即清空（消耗）**。
- pre：`r0=[A,B,C,D]（第 1 份）` `r1=（第 2 份）` `r2=（第 3 份）` `r3=（第 4 份）`
- post：`r0=[Σ,Σ,Σ,Σ]（四段各自的和）` 其余 `空（已交出）`
- 行为集：move、sum
- 轮次：公式 **N−1**；模式：链式，第 k 轮卡 k 把整份发给卡 0，卡 0 折进相加。
  - 第 1 轮边 `1→0`；第 2 轮边 `2→0`；第 3 轮边 `3→0`
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（整包）→ 计算开始 → 计算中 → 计算结束 → 轮歇
  - 锚点：`r1calc.e` `r2calc.e` `r3calc.e` `collapse.e`

### 3.6 allreduce · 全归约（N → N）

- 语义：互换并累加——四份相加，四张卡拿到的和完全一样。
- pre：各持一整份（第 1–4 份）
- post：四张卡都是 `[Σ,Σ,Σ,Σ]`（Σ⁴）
- 行为集：move、sum
- 轮次：公式 **log₂N**（2 轮）；模式：倍增互换，第 k 轮与距离 2ᵏ 的伙伴互换并相加。
  - 第 1 轮边 `0↔1` `2↔3`（横向）；第 2 轮边 `0↔2` `1↔3`（纵向）
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（齐弹）→ 计算开始 → 计算中 → 计算结束 → 轮歇
  - 锚点：`r1merge.e` `r2merge.e` `tail.e`

### 3.7 reducescatter · 归约分散（N → N）

- 语义：相加后切分——四份逐段相加，和切成四段，第 k 张卡只留第 k 段。
- pre：各持一整份（第 1–4 份）
- post：`r0=[Σ,−,−,−]` `r1=[−,Σ,−,−]` `r2=[−,−,Σ,−]` `r3=[−,−,−,Σ]`
- 行为集：move、split、sum
- 轮次：公式 **log₂N**；模式：递归减半，第 k 轮与伙伴互换后各留一半。
  - 第 1 轮边 `0↔2` `1↔3`（同列互换，各收两段）；第 2 轮边 `0↔1` `2↔3`（同行互换，各收一段）
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（齐弹）→ 计算开始 → 计算中 → 计算结束 →（轮间）卡片收窄
  - 锚点：`r1merge.e` `r2merge.e` `tail.e`

### 3.8 alltoall · 全互换（N → N）

- 语义：各切四片互换——每卡把第 k 片发给 rank k；回来后手上是四张卡的第 k 片。
- pre：`r0=[A:0,A:1,A:2,A:3]` …（每卡一份四分片）
- post：`r0=[A:0,B:0,C:0,D:0]` `r1=[A:1,B:1,C:1,D:1]` `r2=[A:2,B:2,C:2,D:2]` `r3=[A:3,B:3,C:3,D:3]`
- 行为集：move、split
- 轮次：公式 **N**（4 步）；模式：按目的地分步，第 q 步其余各卡把第 q 片发给卡 q（每步 3 条边）。
  - 第 1 步边 `1→0` `2→0` `3→0`；第 2 步 `0→1` `2→1` `3→1`；第 3 步 `0→2` `1→2` `3→2`；第 4 步 `0→3` `1→3` `2→3`
  - 轮内相：飞行（数据包）→ 落位延迟 → 落位弹跳（错峰）→ 轮歇
  - 锚点：`r1.e` `r2.e` `r3.e` `r4.e` `tail.e`

## 4. 锚点用法

锚点是 `<轮键>.<s|e>` 形式的时间轴引用（如 `r1merge.e` = 第 1 轮折进相结束），由⑥的相键体系产出，⑧的探针按它采样。锚点集合与②轮次表一一对应，改轮次必须同步锚点。
