## 1. 这是什么项目

CommonVisual：零构建静态可视化站点，用逐步动画讲清 8 种分布式通信原语
（gather / scatter / broadcast / reduce / allgather / allreduce / reducescatter / alltoall）。
纯 HTML + CSS + 原生 JS（`window.CV` + defer），**没有框架、没有打包、没有 ESM**——
「双击 html 就能看」是硬需求。核心入口是根目录 8 个原语页 + index，每页是薄壳、
内容全在 `assets/scenes/<id>.js` 纯数据剧本；规范页在 `docs/`（steps / visual / algorithms /
test-cases 等），经 `../assets/` 引用底层组件。

## 4. 工作规矩（必须遵守）

- **先方案后动码**：规范/语义类改动先出方案、列拍板点，用户放行前不改代码；
  拍板结论沉淀进方案文档，不散落对话。
- **层级铁律**：steps > visual；排查顺序永远是先审 steps 描述、再审 visual 实现。
  **所有规范要求能验证**（新规范进页必须同时挂判定条款+探针——机制建设中，见方案 §3）。
- **单一事实源**：原语语义只写 `assets/registry.js`；可调参数只有 `assets/theme/spec.js`
  （读法 `CV.spec('键')`，禁 `|| 字面量`兜底）；解说动作词只在 `CV.NARR_LEX`。
- **测试**：改完跑 `node tools/verify.mjs <改到的页> --no-shot`；改公共层传 8 原语页 +
  index + docs 三页；push 前全量（用户可明示跳过）。写断言前先 `tools/probe.mjs` 量真值。
- **push**：SSH remote（HTTPS 被代理挡）；推前 `git status` + `git log --oneline` 对齐；
  commit 正文写清「为什么这么改」。
- **收尾**：probe 回归 → README 同步（如涉及）→ `.workbuddy/memory/` 当日日志（只追加）
  → **对话收尾报「耗时分布 + 优化点」**。
- **禁区**：不引入框架/构建/ESM；不做静默重构（公共层改动必须回归）；不发无断言截图；
  `.workbuddy/` 只追加不删改且不进 git；内容源 `分布式通信原语详解.md` 只读。
- 历史坑一句话清单在 `AGENTS.md` §5——动码前先读它。
