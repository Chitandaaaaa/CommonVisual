# 剧本

八原语动态页的内容设计文档。只写描述，不写数值——部件长相查《组件文档》，
节奏秒数归《特效动画》。章＝设计层（布局 / 步骤 / 动作），节＝原语；
原语顺序沿 registry 先序。

## 编写规则

1. 用词查《术语表》（[术语表.md](术语表.md)）；新词先入表再使用。
2. 部件长相按名称查《组件文档》；取值符号直接用「全部类型」词面（如 ΣA4、
   数据包ABCD）；不抄参数，本册不写数值。术语或组件状态已含的属性（如
   发送态的描边）不重复描述，额外属性归入其组件定义。
3. 布局分**开场、结束**两张（1.x.1 / 1.x.2），各按**目标卡、源卡、连线、图例**
   四方面描述（四张卡同权、不分源卡与目标卡的页合写为「卡片」）；结束与开场
   相同的方面只写「不变」。
4. 描述用主谓宾：谁、显示 / 隐藏 / 变作 / 送出什么；未显形或数据已送出的
   数据格写「是隐格」；不下结论。
5. 先后关系写在句内：用「先／再／随后」表达顺序，不拆编号步骤。
6. 步骤每步一句，写清谁把什么包发给谁、落进第几排第几格。
7. 动作按时刻分组（同一时刻同一子标题，串行换下一子标题）；步标 3.x.y，
   步内拍标①②③，沟通地址＝3.x.y①。**每两个相邻拍之间都有一个等待拍**
   （纯等待，静止不动）；每个非静止步以「等待下一步开始」收尾。

## 第 1 章 布局

**1.1.1 开场布局**

- 目标卡：三张，在右排成一列；都是单排卡，各一排四个数据格；四个数据格全是隐格。
- 源卡：一张，在左；单排卡，一排四个数据格；装满数据块 A B C D。
- 连线：源卡和每张目标卡之间各一条，共三条，都是弧线箭头，从源卡指向目标卡。
- 图例：源卡旁边放一个图例框。

**1.1.2 结束布局**

- 目标卡：三张各装满数据块 A B C D。
- 源卡：不变。
- 连线：不变。
- 图例：不变。

## 第 2 章 步骤

### 2.1 broadcast

1. 开场说明：源卡显示装满的四个数据块 A B C D。
2. 预留缓冲：三张目标卡各依次显示四个空数据格。
3. 广播给 B：源卡复制数据包ABCD发给第一张目标卡，四个数据块落进第一张目标卡的四个数据格。
4. 广播给 C：同样复制给第二张目标卡。
5. 广播给 D：同样复制给第三张目标卡。
6. 完成：三张目标卡各装满 A B C D，源卡不变。

### 2.2 scatter

1. 开场说明：源卡显示装满的四个数据块 A B C D。
2. 预留缓冲：三张目标卡各依次显示一个空数据格。
3. 传递 B：源卡把数据包B发给第一张目标卡，数据块 B 落进目标卡的数据格。
4. 传递 C：源卡把数据包C发给第二张目标卡，数据块 C 落进目标卡的数据格。
5. 传递 D：源卡把数据包D发给第三张目标卡，数据块 D 落进目标卡的数据格。
6. 收场：源卡第 2 格到第 4 格依次变作隐格。
7. 完成：三张目标卡各装一个数据块；源卡装一个数据块 A，其余三个数据格是隐格。

### 2.3 gather

1. 开场说明：四张卡各自显示持有的数据块：目标卡一块 A，三张源卡 B、C、D。
2. 预留缓冲：目标卡依次显示三个空数据格。
3. 传递 B：源卡 1 把数据包B发给目标卡，数据块 B 落进第 2 格。
4. 传递 C：源卡 2 把数据包C发给目标卡，数据块 C 落进第 3 格。
5. 传递 D：源卡 3 把数据包D发给目标卡，数据块 D 落进第 4 格。
6. 完成：目标卡集齐 A B C D，三张源卡各留自己的数据块。

### 2.4 allgather

1. 开场说明：四张卡各显示一个数据块——A、B、C、D。
2. 预留缓冲：四张卡各依次显示三个空数据格。
3. 第 1 轮：沿环顺时针，四张卡各把手上的数据块装进数据包发给环上的下一张卡，数据块落进目标卡同字母的数据格，徽章跳到 2/4。
4. 第 2 轮：沿环顺时针，各卡把上一轮拿到的数据块装进数据包发给环上的下一张卡，各卡手上凑到三块，徽章跳到 3/4。
5. 第 3 轮：沿环顺时针，各卡把上一轮拿到的数据块装进数据包发给环上的下一张卡，各卡手上的块凑满四块。
6. 完成：四张卡都集齐 A B C D，徽章 4/4。

### 2.5 reduce

1. 开场说明：四张卡各显示装满的四个数据块 A B C D。
2. 预留缓冲：目标卡变作双排卡，依次显示第二排的四个空数据格。
3. 传递：第一张源卡把数据包ABCD发给目标卡，四个数据块落进第二排的四个空数据格。
4. 计算：计算层先出现，计算方牌再显示，第二排的四块逐段计算，上排同字母的数据格各变作规约数据块 ΣA2 ΣB2 ΣC2 ΣD2；随后计算方牌消失、卡片隐藏计算层。
5. 传递：第二张源卡把数据包ABCD发给目标卡，四个数据块落进第二排的四个空数据格。
6. 计算：计算层先出现，计算方牌再显示，第二排的四块逐段计算，上排同字母的数据格各变作规约数据块 ΣA3 ΣB3 ΣC3 ΣD3；随后计算方牌消失、卡片隐藏计算层。
7. 传递：第三张源卡把数据包ABCD发给目标卡，四个数据块落进第二排的四个空数据格。
8. 计算：计算层先出现，计算方牌再显示，第二排的四块逐段计算，上排同字母的数据格各变作规约数据块 ΣA4 ΣB4 ΣC4 ΣD4；随后计算方牌消失、卡片隐藏计算层。
9. 收场：目标卡把第二排的空数据格依次变作隐格、双排卡变作单排卡，三张源卡的空数据格依次变作隐格。
10. 完成：目标卡一排 ΣA4 ΣB4 ΣC4 ΣD4，三张源卡的数据格全部是隐格。

### 2.6 allreduce

1. 开场说明：四张卡各显示装满的四个数据块 A B C D。
2. 预留缓冲：四张卡同时变作双排卡，依次显示第二排的四个空数据格。
3. 第 1 轮传递：横向两对卡（0 与 1、2 与 3）互相传递数据包ABCD。
4. 计算：收到的四块落进第二排，计算层先出现，计算方牌再显示，四段逐段计算各合 2 份——上排各变作规约数据块 ΣA2 ΣB2 ΣC2 ΣD2；随后计算方牌消失、卡片隐藏计算层。
5. 第 2 轮传递：纵向两对卡（0 与 2、1 与 3）互相传递规约数据包，包里各是规约数据块 ΣA2 ΣB2 ΣC2 ΣD2。
6. 计算：收到的四块落进第二排，计算层先出现，计算方牌再显示，四段再计算一次，各合成 4 份——上排各变作规约数据块 ΣA4 ΣB4 ΣC4 ΣD4；随后计算方牌消失、卡片隐藏计算层。
7. 收场：四张卡把第二排的空数据格依次变作隐格，双排卡变作单排卡。
8. 完成：四张卡各显示一排规约数据块 ΣA4 ΣB4 ΣC4 ΣD4。

### 2.7 reducescatter

1. 开场说明：四张卡各显示装满的四个数据块 A B C D。
2. 预留缓冲：四张卡同时变作双排卡，依次显示第二排的四个空数据格。
3. 第 1 轮传递：纵向两对卡（0 与 2、1 与 3）互相传递数据包AB与数据包CD，各卡把对方要的两段送出。
4. 计算：收到的两块落进第二排同字母的数据格，计算层先出现，计算方牌再显示，两段逐段计算各合 2 份——上排各变作规约数据块：0 与 1 是 ΣA2 ΣB2，2 与 3 是 ΣC2 ΣD2；随后计算方牌先消失、卡片再隐藏计算层，再隐藏第二轮用不上的空数据格。
5. 第 2 轮传递：横向两对卡（0 与 1、2 与 3）互相传递规约数据包，包里各是一个规约数据块——0 与 1 互传 ΣB2 与 ΣA2，2 与 3 互传 ΣD2 与 ΣC2。
6. 计算：收下的块落进第二排同字母的数据格，计算层先出现，计算方牌再显示，这一段计算合成 4 份——号位格各变作规约数据块：0 是 ΣA4、1 是 ΣB4、2 是 ΣC4、3 是 ΣD4；随后计算方牌消失、卡片隐藏计算层。
7. 收场：四张卡把空数据格依次变作隐格，双排卡变作单排卡。
8. 完成：各卡号位格显示一个规约数据块——0 是 ΣA4、1 是 ΣB4、2 是 ΣC4、3 是 ΣD4；其余数据格是隐格。

### 2.8 alltoall

1. 开场说明：四张卡各显示上排的四个分片数据块——A0–A3、B0–B3、C0–C3、D0–D3。
2. 预留缓冲：四张卡变作双排卡，依次显示下排的四个空数据格。
3. 发第 1 片：各卡把第 1 片装进数据包发给 rank0（自己那片原地不动），落进对方下排同字母的数据格。
4. 发第 2 片：各卡把第 2 片装进数据包发给 rank1（自己那片原地不动），落进对方下排同字母的数据格。
5. 发第 3 片：各卡把第 3 片装进数据包发给 rank2（自己那片原地不动），落进对方下排同字母的数据格。
6. 发第 4 片：各卡把第 4 片装进数据包发给 rank3（自己那片原地不动），落进对方下排同字母的数据格。
7. 收场：四张卡把上排的空数据格依次变作隐格，双排卡变作单排卡，数据块装满单排。
8. 完成：四张卡单排各装满数据块 A B C D。

## 第 3 章 动作

动作＝每步内部拆开的舞台行为序列：谁、对什么部件、做什么。每步内按**时刻**
分组：同一时刻同时进行的动作放在同一个子标题下，串行的换下一个子标题。
步标 3.x.y，步内拍标①②③，沟通地址＝3.x.y①（如 3.1.3③＝broadcast 第 3 步
的「飞行」拍）。**传递步按模板**：出现（进发送态＋数据格状态转化）→
飞行（从起点沿方向到终点）→ 抵达（淡出直至消失、源卡复原、连线余辉后
回闲置）→ 落位（数据块落进对应格）→ 结束（空数据格回收等，不一定有）。
**每两个相邻拍之间都有一个
等待拍**（纯等待，静止不动）；每个非静止步以「等待下一步开始」收尾。每拍
描述成完整过程：有**起点、方向、终点**（或**开始、经过、结束**），等待拍与
静止拍除外。只写动作与先后，不写秒数——秒与缓动归《特效动画》。节＝原语，
与第 1、2 章同序。

### 3.1 broadcast

**3.1.1 开场说明**

- ① 无动作，全台静止。

**3.1.2 预留缓冲**

- ① 显形：三张目标卡同时开始，每卡四个隐格自第 1 格到第 4 格依次显形，至整排变作空数据格。
- ② 等待：全台静止，等待下一步开始。

**3.1.3 广播给 B**

- ① 出现：源卡进发送态；连线转飞行态；数据包ABCD出现在连线起点，就位待发；目标卡四个数据格转接收态。
- ② 等待：全台静止，等待数据包起飞。
- ③ 飞行：数据包ABCD从连线起点起飞，沿连线朝目标卡方向飞行，抵达连线终点——目标卡一侧的箭头尖。
- ④ 等待：全台静止，等待数据包淡出。
- ⑤ 抵达：数据包开始淡出，连线同时转余辉态；数据包消失后，连线变回闲置态，源卡复原。
- ⑥ 等待：全台静止，等待数据块落位。
- ⑦ 落位：四个数据块从数据包齐落进目标卡四个数据格，整组弹跳一次后静止。
- ⑧ 等待：全台完全静止，等待下一步开始。

**3.1.4 广播给 C**：动作同步 3.1.3（①–⑧），目标卡换第二张。

**3.1.5 广播给 D**：动作同步 3.1.3（①–⑧），目标卡换第三张。

**3.1.6 完成**

- ① 无动作，全台静止，终态停驻。

### 3.2 scatter

**3.2.1 开场说明**

- ① 无动作，全台静止。

**3.2.2 预留缓冲**

- ① 显形：三张目标卡同时开始，各卡的隐格显形，变作空数据格。
- ② 等待：全台静止，等待下一步开始。

**3.2.3 传递 B**
