# 组件文档

## 第一章 卡片

卡片是舞台上的参与者（rank 0–3），白底圆角矩形：顶部一条彩色标题栏，栏里放标题和徽章，下方空白区装一排（或多排）数据格。两种形态：**单排卡**（初始态）和**双排卡**（长高后）。

### 1.1 单排卡

```
┌──────────────────────────────────┐ ← 卡片本体
│ 标题                       [src] │ ← 标题栏：左标题、右徽章
├──────────────────────────────────┤
│                                  │
│  ┌────┐  ┌────┐  ┌────┐  ┌────┐  │ ← 空白区
│  │ A  │  │ B  │  │ C  │  │ D  │  │    一排数据格
│  └────┘  └────┘  └────┘  └────┘  │
│                                  │
└──────────────────────────────────┘
```

## 第四章 连线与箭头

## 第五章 数据包

沿连线从发送卡飞向接收卡的数据本体。

### 5.1 单个数据包（飞行中）

#### 5.1.1 包体

| 参数 | 值 |
|---|---|
| 尺寸（宽×高） | 24×24 |
| 圆角 | 6.5 |
| 底色 | 该 rank 数据色（同 1.1.2 四色） |
| 发光 | 模糊 8、不透明度 0.22 |

#### 5.1.2 文字

| 参数 | 值 |
|---|---|
| 内容 | 该 rank 字母（A、B、C、D） |
| 字号 | 13 |
| 字体 | Consolas |
| 字重 | 700 |
| 颜色 | #ffffff |
| 位置 | 包体中心 |

#### 5.1.3 拖尾

两段递减，永远拖在来路上：

| 参数 | 值 |
|---|---|
| 尺寸 | 近段 20×20 · 远段 16×16（再各缩 0.8 / 0.6） |
| 圆角 | 近段 5.5 · 远段 4.5 |
| 浓度 | 近段 0.55 · 远段 0.28 |
| 退后 | 近段 24 · 远段 46 |
| 滤镜 | 模糊 5、不透明度 0.14 |

### 5.3 动态

| 参数 | 值 |
|---|---|
| 起飞渐显 | 前 8% 行程透明度 0→1 |
| 飞行时长 | 1.5s |
| 送达淡出 | 停在终点，0.6s 降到透明 |
| 落位 | 淡出后延迟 0.5s，数据块在格内弹跳 0.55s，多块错峰 0.5s |
