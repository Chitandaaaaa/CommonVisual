04

标准件目录

这是目标态的标准件清单：全部 36 件，也是 05 目标架构的唯一词汇表。 每件只回答三件事 —— 它干什么、对外露出什么、读谁 / 被谁读 / 能写谁。 四段编号 R 运行时 · P 页面 · S 样式 · T 工具，数字就是层序。

R 运行时 · 14
P 页面 · 12
S 样式 · 5
T 工具 · 5
L0 令牌 L1 工具 L2 绘制 L3 配置 L4 骨架 L5 装配 L6 页面
编号的底色 = 它所在的层。 依赖行读法：← 它读谁　被 谁读它　✎ 它能触发写盘。 落盘一律经 T01，被写的文件只有 R01 / R02 / R07 三件，其余 33 件运行时只读，只能人用编辑器改。
R 运行时assets/cv/ · L0–L5 · 14 件 · 编号底色就是层色
R01
tokens.css L0 令牌
全站唯一的 :root：色板、圆角、字号、间距。任何样式表都不再自带变量定义，只 link 它。
契约 --bg --panel --line --tx --accent …（纯 CSS 变量，无 JS API）
← 无　被 S01–S05　✎ T01
R02
tokens.js L0 令牌
参数的出厂值 CV_PARAM_DEFAULTS。必须早于 R05 / R06 加载，所有参数从它起步。
契约 window.CV_PARAM_DEFAULTS
← 无　被 R05 R06 R07　✎ T01
R03
dom.js L1 工具
DOM / SVG 的构造与查询：建元素、写属性、取包围盒、锚点跳转。8 个 API，无业务语义，可整体替换。
契约 CV.el · attr · box · showSection
← 无　被 R04 R05 R08 R09 R10 R14
R04
save.js L1 工具
存档 IO：把参数写成代码、POST /__cv/save、导出日志；服务端不在时退化成下载文件。
契约 CV.saveFile(target, payload)
← R03　被 R14
R05
kit.js L2 绘制
唯一会画东西的件。draw* 原语、几何 geo / GEO_BASE、色板 PALETTE；只按参数画形状，不认识页面语义。
契约 CV.drawCard · drawSlot · drawWire · drawPacket · geo
← R03　被 R08 R13 R14 与 P01–P08
R06
params.js L3 配置
参数注册表：SCHEMA 分节、取默认值、读写、改动通知、localStorage 覆盖。纯数据，不画图。
契约 CV.params.get · set · specVal · specGroup · onChange
← R02　被 R13 R14 与全部页面
R07
pages/<page>.js L3 配置 · ×4
每页的时序基线 CV_PAGE_DEFAULTS，一页一个文件。改 A 页的时序不会碰到 B 页的文件。
契约 CV_PAGE_DEFAULTS（按页一份，互不可见）
← R02　被 R08 R13　✎ R13 / T01
R08
primitive.js L4 骨架
8 页共用骨架。buildStage + mount 生命周期：卡、槽、连线、数据包、落位弹跳、时钟都在这里。
契约 CV.primitive(cfg) → { reload, … }
← R03 R05 R09 R10　被 P01–P08 · R13

controls.js L4 骨架
控制条：进度条、播放暂停、字幕、全局键盘。带 destroy()，只有 root === document 时才绑全局键。

← R03　被 R08 与全部 12 页

页面顶部的关系导航。纯渲染器：读拓扑画节点与跳转，自身不含任何原语数据。

原语拓扑的唯一事实源：关系 REL、中英名、页址。index 树、对照表、导航都读它，谁也不许再抄一份。

05

目标架构

不引入框架、不引入构建。用 04 的 36 件标准件装配 —— 图里每个方块写着它的编号，读图即读目录。本节末尾另附「怎么走到这里」的五次搬家。

读只向下、编号只变小、写只发生在 L3 且一页一个文件 —— I1、I2、I3 同时成立
一条装配链长什么样
以 gather 页为例：它不「调用」这一串，而是声明自己依赖谁，由下层把舞台搭好。链上每一步都指向更小的编号。
运行时能写的地方，全在这
「I1 页面独占」落地后，程序运行期间可写的目标只剩三处，且互不重叠。其余 33 件只有人用编辑器才能改。
写什么谁写什么时候影响范围
R07 pages/<page>.js R13 齿轮（经 T01 落盘） 页面内改时序参数并点保存 只这一页
R02 tokens.js R14 调试台（经 T01 落盘） 规范页改组件规范并点保存 全站组件
R01 tokens.css T01（手工改，或未来由 R14 生成） 改主题色 / 间距 全站外观
localStorage R06 · R13 页面内临时改值（不落盘，刷新仍在） 本机本页
其余 33 件 人（编辑器） 开发时 按 06 的判据分任务
