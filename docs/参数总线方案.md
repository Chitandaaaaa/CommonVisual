# 参数总线方案（2026-11-02 定稿）

> 目标三条：① 舞台上可见的一切参数都能控；② 同一配置只在一处；③ 底层低耦合高内聚。
> 附加两条：架构规范同步改；每页用例保证「可见即可验」。
> 界面约束：几何、颜色可调但**默认锁定**，面板有总开关解锁；锁只门禁 UI，不动数据层。

## 0. 一句话

把现有 `CV.params`（三级取值 + 调试台 + 保存到代码）升格为全站唯一的参数总线：**一张表、一个读法、一条链**；
表（SCHEMA）同时驱动面板控件、规范总账、探针用例、CSS 变量四样产物，「可见 ⇒ 入表 ⇒ 可验」由同一条数据保证。

## 2. 骨架

### 2.1 一张表 `assets/theme/spec.js`（纯数据，人写）

每键入表门槛（缺一不许入表；B2–B4 逐步补齐字段）：

```
popDur: { label, def, min, max, step, unit,
          kind : 'num' | 'px' | 'color' | 'curve',   // 面板出什么控件
          scope: 'site' | 'page',  pages: P8 | [...], // 哪些页可见
          sink : 'js' | 'css' | 'both',               // 谁消费
          chk  : 'link' | 'truth' | 'unit' | 'css',   // 怎么验
          read : 'slot-pop@animationDuration' }       // truth/css 型必填：DOM 哪里量
```

收录边界：**只收舞台可见物**（卡片、槽位、数据包、计算框、连线、图例、落位特效、编排秒、几何、颜色、曲线）。
页面 chrome（播放键、进度条、面板自身样式）不入表。

### 2.2 一个读法 `CV.spec(key)`

按键名查，表外键直接 throw（与 `CV.NARR_LEX` 同款铁律），返回当前数值原样。
**消费端禁止 `|| 字面量` 兜底**——默认值只有表能给。`CV.params.get(组,键)` 退为内部实现。

### 2.3 一条链

取值优先级不变：① SCHEMA.def（出厂值）→ ② defaults.js（基线，机器写）→ ③ localStorage（运行时）。
页级覆盖并入同一条链（键带页前缀），`CV_PAGE_DEFAULTS` / `cv.page.*` / `pageOv*` 退役；「保存到代码」仍分写 defaults.js 与 pages-base.js 两个文件。

### 2.4 分层

```
spec.js       纯数据 SCHEMA（人写）
defaults.js   基线快照（机器写）
params.js     store：seed/get/set/reset/onChange + CSS sink（kind=color|duration 且 sink 含 css → setProperty('--cv-<key>')）
──────────────────────────────────────────────
engine / parts / prim   只读 CV.spec(key)
stage-page.css          只读 var(--cv-<key>)，舞台选择器下禁裸数值
ledger.js               Y 行改 LIVE()，总账 = SCHEMA 视图 + 少数结构性真值
面板渲染核（blocks）     一个渲染核、两个壳：原语页齿轮「外观」tab + 规范页抽屉
```

## 3. 界面

- 原语页「时序」齿轮升级为统一面板：tab ①「本页时序」（现有，page scope）／tab ②「全站外观」（SCHEMA 中 sink=stage 的组）。
- 规范页 ⚙ 抽屉换同一渲染核，功能不变（章节联动、重置、导出、保存到代码）。
- **锁**：所有行默认只读（禁用态显示当前值）；面板头部一个总开关「解锁编辑」；锁上 ≠ 回基线；不持久化（刷新回锁定）；探针不走 UI 不受锁影响。
- 几何按当前模式（桌面/窄屏）显示与编辑，另一套收子分组、只存不预览；几何改动经 `api.reload()` 重建舞台。
- 「保存到代码」对几何、颜色同样生效。
