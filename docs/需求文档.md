# CommonVisual 需求文档

> **本文只写「产品要做什么」（功能点），不写「怎么做」**——不涉及代码、文件组织与实现方式。
> 依据 2026-11-01 的 v2 现状反推整理；功能增删应同步本页。
> 口径基准：解说文案看 `docs/steps.html`，组件真值看 `docs/visual.html`，算法口径看 `docs/algorithms.html`，验收用例看 `docs/test-cases.html`。

---

## 1. 产品定位

- 用**逐步推进的数据流动画**，讲清 NCCL 集合通信的 8 种原语：gather（收集）、scatter（分散）、broadcast（广播）、reduce（归约）、allgather（全收集）、allreduce（全归约）、reduce-scatter（归约分散）、all-to-all（全互换）。
- **目标读者**：学习分布式训练 / 集合通信的工程师与学生；每个动画看一遍，就能看懂一种原语「通信前各卡有什么 → 通信后各卡有什么」以及它用的算法骨架。
- **体验目标**：双击即看、零门槛；动画自解释，配同轨解说与逐动作步骤表。

## 2. 交付与运行形态（非功能需求）

1. **双击即看**：直接双击 HTML 文件即可在浏览器打开并使用全部功能，不需要任何安装、构建或启动步骤。
2. **零依赖**：页面运行不依赖任何外部库、字体或网络资源；离线可用。
3. **可上线**：也可托管为纯静态站点对外访问（如 GitHub Pages）。
4. **浏览器**：支持主流现代浏览器（Chrome 系为准）。
5. **语言**：界面与解说全部中文；原语名保留英文。
6. **响应式**：桌面与窄屏（手机宽度）两套布局自动切换；切换时舞台几何重排、字幕换短文案，且**不丢失当前播放进度**。
7. **稳定性**：页面加载与全部交互过程中不出现脚本错误；功能异常不允许伪装成正常。

## 4. 首页

1. **开场区**：三行大标题逐行淡入，「画」字悬停有扫光动效；一句副标题简介。
2. **主行动**：主按钮「看 Gather 跑一遍」直达第一个原语动画页。
3. **原语关系树**：8 张节点卡 + 关系连线，按原语派生关系排成树。
   - 节点卡上排：点亮该原语参与的 rank 圆点 + 英文名；下排：中文名 + 方向标签（`1→N` / `N→1` / `N→N`），方向必须与该原语语义一致。
   - 整卡是链接，点击进入对应原语页。
4. **悬停聚焦**：悬停 / 键盘聚焦某节点时，点亮该节点与「从它射出」的连线，其余不变。
5. **入场动效**：连线播一次「描边生长 + 流光」，节点卡错峰入场；滚动离开再回来不重播。
6. **缩放**：首页整体随屏宽等比放大 / 缩小，保持构图不变。

## 5. 原语动画页（产品核心）

8 页共用同一套骨架与交互，只有动画剧本内容不同。

### 5.1 页面骨架

- **页头**：原语英文名大标题；右上角「⚙ 时序」按钮（打开时序面板）；标题旁嵌关系导航。
- **舞台**：页面主体，全部动画在其中呈现；角落常驻图例（一整份 = A / B / C / D 四块）。
- **控制条**：字幕 + 分段进度条 + 播放控件（见 5.3）。
- **无障碍基础**：舞台动画提供概括性文字描述（如「XX 通信过程动画」）；控件带名称（播放 / 暂停）。

### 5.2 舞台视觉语言

1. **rank 卡片**：每卡专属色标题条 + 右上角徽章（角色 `src` / `dst`、进度 `1/4` 或容量 `4 段` / `4 片`，随动画更新）；目标卡描边更粗呈紫色。
2. **数据槽三态**：有数据（彩色块 + 字母）、等待接收（浅色「···」）、空（虚线框）。**送出去的那格显示为「空」**，不是接收位。
3. **数据字母体系**：A / B / C / D 四色；可带下标（第几片，如 A₀）与上标（已折进几份，Σ² → Σ⁴），全站颜色语义一致（rank 与数据块同色系）。
4. **连线**：带箭头的虚线，颜色跟随数据流语义；一条流一个箭头、互不共用（改一条边的颜色不影响别的边）。
5. **飞行数据包**：渐显起飞、沿连线飞行、带拖尾（拖尾始终朝来路）；抵达后落位弹跳，随后淡出。整份传递时用「整份包」（托板内四块）。
6. **落位节奏两口径**：顺序到达的包依次错峰弹跳；同一批同飞的包同刻齐弹。
7. **计算表达**（reduce / allreduce / reduce-scatter 三页）：卡片临时长高浮出「计算」方框，悬停显示可用运算符气泡（桌面 sum·avg·max·min，窄屏 sum·avg），算完收回；融合动画把下方数据「吸」进目标格，白光扫过后变为 Σ。
8. **发送中变暗**：正在发送的卡片整体降透明度，作为「正在发送」的唯一可视信号。

### 5.3 播放器

1. 进入页面**自动开始播放**；播完**自动从头循环**（常开，无开关）。
2. **播放 / 暂停**主按钮，图标与名称随状态切换。
3. **上一步 / 下一步**：跳到相邻步骤的起点，并暂停播放。
4. **分段进度条**：每步一段；**段宽与该步真实时长成正比**（不允许等宽分段）；段内填充跟随播放推进；**拖动可定位到任意时刻，拖动即暂停**（松手不自动恢复）。
5. **字幕**：显示当前步的解说文案，内嵌彩色标签（rank 色片、数据块色片、Σ 片）；窄屏自动切换为该步的**短文案**。
6. **键盘快捷键**：空格 = 播放 / 暂停；← / → = 上一步 / 下一步；R = 停止并回到开头。输入框聚焦时快捷键豁免；焦点在按钮上按空格不双触发。
7. **回绕干净**：循环回到开头的那一帧与首次播放完全一致——块数、文字、包与透明度全部复位，无上一轮残留。
8. **终态干净**：播放到结尾时无中间元素残留（飞行包、脉冲、特效全部消失）。
9. **时序连续**：相邻步骤时间窗首尾相接，无空档、无重叠；调整耗时后仍成立。

### 5.4 聚焦交互

1. **悬停聚焦**：悬停舞台上任何带字母的元素（数据块 / 包 / 连线）→ 同字母元素保持彩色，其余元素缓缓褪灰；无关连线变细变淡，无关卡片标题条变灰。
2. **钉住**：点击同一字母可「钉住」聚焦（刷新前常驻），再点解除。
3. 部分页面（broadcast、reduce-scatter 等）聚焦时**保留全部卡片**不灰化。

### 5.5 时序面板（齿轮 · 页签一）

1. **入口**：页头右上「⚙ 时序」；弹层可点击外部或 Esc 关闭，随窗口变化重新定位。
2. **每行 = 进度条的一个编号段**：编号、名称、输入框。顶部提示「编号＝进度条第几段 · 有规范值调倍数 · 自定义填秒 · 改完自动存到本机」。
3. **两类行**：时长由全站规范决定的段，调**倍数**（悬停可看换算明细）；页面自定义的段，直接填**秒**。徽记区分两类。
4. **按轮分组**：有重复结构的页面（reduce / allreduce / reduce-scatter / alltoall）把重复段落按轮折叠成组行展示（如「第 1 轮 · 同列互换」「互换一轮 ×2」），组内为子行样式；分组不改变进度条段数。
5. **改动即时生效**：总时长实时更新、进度条按新时长重新分段（段宽仍与时长成正比），且**保留当前播放位置**不跳变。
6. **重置**：每行可单独重置；底部「全部重置」清除本页全部本机改动。
7. **反馈**：底部实时显示整轮总时长；保存 / 恢复操作有短暂提示条。
8. **本机持久化**：改动自动保存在本机浏览器中，刷新后仍生效。
9. **保存到代码**（维护者功能）：把当前页的时序固化为项目基线；本地开发服务下直接写回文件，其他打开方式自动退化为下载文件，并说明原因。

### 5.6 逐动作解说面板（齿轮 · 页签二）

1. **解说表**：按时间顺序每个动作一行——编号 | 开始 | 结束 | 解说 | 结果。
2. **分组**：按步分组，组头行显示组名、起止秒与时长；同一时刻发生的动作合并开始格并标注「同刻 ×n」；瞬时动作结束格留空；静止说明行灰化。
3. **实时高亮**：正在播放的行实时高亮。
4. **跟随播放**：开启后高亮行自动滚动到列表中部附近；手动滚动后跟随暂停 2 秒再自动恢复；可手动开关。
5. **面板内播放控件**：播放 / 暂停钮与底部控制条、空格键**三方状态同步**（任一入口切换，其余跟随）。
6. **倍速钮**：− 放慢 / ＋ 放快，在 0.25 / 0.5 / 1 / 2 / 4 五档间步进，到端点按钮禁用，显示当前倍率。倍速**只影响播放推进速度**，不改动画本身的节奏定义，且是**会话内临时状态**（刷新回 1×）；倍速下拖动进度仍精确落点，分段条与高亮不受影响。
7. **解说文案来源**：动作词全部出自全站统一词表；解说表与实际动画逐行一致（见 §8）。

### 5.7 各页剧本差异

| 页面 | 一句话语义 | 舞台布局 | 卡片徽章 | 步骤组织 | 特有元素 | 时序分组 |
|---|---|---|---|---|---|---|
| gather | N 段拼成一份，只有 rank0 长大 | 单列，目标卡在左 | src/dst | 逐段飞入，目标卡计数上标 | — | 无 |
| scatter | 一份拆成 N 段分给各人 | 单列，源卡在左 | src/dst | 逐段腾空拆分 | — | 无 |
| broadcast | 一份复制给 N 人，人人整份 | 左 1 源卡 + 右 3 列 | src/dst | 说明 → 接收位就绪 → 逐个广播 ×3 → 收尾 | — | 无 |
| reduce | N 份相加成一份，累加器逐段折入 | 单列 + 计算方框 + 卡片长高 | dst | 说明 → 预留 → 折一份 ×3 → 收场 | 计算框、融合 | 「折一份 ×3」 |
| allgather | 人人拿到全集 | 2×2 网格 | 进度 1/4→4/4 | 顺时针 3 轮整份互发 | 槽位含等待 / 已收区分 | 无 |
| allreduce | 相加后每人一份 | 2×2 + 第二排 + 计算方框 | 4 段 | 两轮整份互换，每轮「传递→落位→计算→合并」 | 计算框、融合、双向双车道 | 「互换一轮 ×2」 |
| reduce-scatter | 相加后按段切开，每卡留自己那段 | 2×2 + 第二排 + 计算方框 | 4 段 | 递归减半两轮，每轮五相 | 计算框、融合 | 「第 1 轮 · 同列互换」「第 2 轮 · 同行互换」 |
| all-to-all | 每人发一段收一段 | 2×2，上排待发、下排已收 | 4 片 | 12 条消息按目的地分 4 步 | 切片下标、连线无箭头 | 「发送一步 ×4」 |

### 5.8 内容正确性

1. 每页动画的**初始布局与终态必须与「前后对照表」逐格一致**；对照表是唯一事实，不允许从动画反推。
2. 起点语义边界明确：gather / allgather 通信前各持**一片**；reduce / allreduce / reduce-scatter 通信前各持**一整份**。
3. 数据语义不混用：**送出是消耗**（scatter、reduce 家族），**broadcast 才是复制**；gather / broadcast 终态发端不清空，scatter / reduce 终态源端清空。
4. scatter 与 gather 的核心区别必须可见：scatter 源卡逐段腾空，gather 源卡保留。
5. reduce 是**边收边算**（每份到达即折入累加器，不是攒齐再算）；reduce-scatter 全程**不得出现「先合成整份 Σ 再切开」的中间态**。
6. all-to-all 必须画两排缓冲：上排待发逐片清空、下排已收按步填满。
7. 页面显示的时间数值（总时长、每步秒数）与实际播放一致，不允许手写漂移。

## 6. 参数体系（全站）

1. **两套参数互不相干**：
   - **全站动效参数**：卡片伸缩、飞行时长、拖尾、弹跳、融合、全局播放速度等；改后立即作用于**所有**用到该动效的页面与示例。
   - **每页时序参数**：该页每一步的耗时；只作用于本页（见 5.5）。
2. **取值优先级**：内置默认 ← 项目基线 ← 本机改动；本机改动自动持久化、刷新仍生效。
3. **重置只清自己**：每页时序的「全部重置」只清本页时序；动效调试台的「重置全部」只清动效参数。
4. 每个参数行支持**单独重置**。
5. 动效参数改动**即时重绘**所有相关示例，无需刷新。
6. **两种「速度」严格区分**：全局播放速度（持久化，改变动画节奏定义）与解说面板倍速（会话临时，只影响播放推进）。
7. **维护者能力**：动效调试台与每页时序面板均可「保存到代码」固化基线（直写 / 下载降级）；动效调试台还可导出当前参数为日志文件。

## 7. 规范文档页

规范页与动画页互不依赖，但都使用同一套舞台组件；每页自身也是可交互的网页。

### 7.1 前后对照表（docs/prepost.html）

1. 八个原语小节，每节：中英文名 + 方向标签 + 一句话说明 + 左「通信前」右「通信后」对照。
2. 每行 rank 标签 + 彩色格 + 结果旗标（如「拼成 4 段」「已交出」）；**未变化的行置灰**。
3. 中部显示动作词（复制 / 拼接 / 相加…）与方向箭头。
4. 页头图例统一写法：`A`、`A₀`（第几片）、`Σ`、空白格（本卡没有这段）、置灰（未变化）。
5. 左侧锚点栏**随滚动高亮**当前原语；页脚互链算法口径、组件规范与首页。

### 7.2 算法口径（docs/algorithms.html）

1. 每个原语一节：通信前 / 骨架 / 常用实现 / 轮次 / 终态 / 锚点。
2. 骨架用点阵矩阵表达：实心 = 常见默认、空心 = 也可用、× = 走不通，悬停有说明。
3. 轮次行给出：几轮、轮数公式、轮内相、每轮动哪些边、模式与出处；缺项显示「待补」。
4. 下部三章：**八种骨架怎么走**（每骨架的轮数 / 强项 / 软肋）、**All-Reduce 三条路线**（流程图，默认路线高亮）、**NCCL 怎么选**（选型表 + 协议说明）。
5. 附变更日志。

### 7.3 组件与动效规范（docs/visual.html）

1. 13 个章节，**单章视图**：左侧目录点击切节；右侧自动生成「本节子目录」（宽屏显示），点击平滑滚动并更新地址栏。
2. **网址锚点两级深链**：`#sec-05` 直达某节、`#sub-05-4` 直达某小节。
3. 每节示例是**真实组件 1:1 渲染**并叠加尺寸标注；动态示例持续播放。
4. **参数调试台**：右下角悬浮钮展开整高抽屉；默认只列当前章节的参数组（随切节联动，可切「全部章节」）；每组可跳回正文对应位置；每参数一行（滑杆 + 数字 + 单位 + 单行重置），**拖动即时重绘全部示例**。
5. 调试台底栏：变更计数、重置全部、保存到代码（直写 / 下载降级）、导出日志。
6. 窄窗口自动收起抽屉，不遮挡正文。

### 7.4 逐动作解说规范（docs/steps.html）

1. 纯文档页：面板示意图、**名词表**（卡名写法、卡片、槽与块、连线与运动体、动作谓语核心表、包的一生顺序律）。
2. 八页总览表（方向 / 步 / 节 / 秒）+ 每个原语一节的完整解说表（与 5.6 面板同构：分组行、同刻合并、瞬时行、静止行）。
3. 时间与高亮机制说明、拍板记录与变更日志。
4. 手写稿必须与实际动画**逐行一致**（步数、行数、总秒、每行起止），并有自动对账把关（见 §8）。

### 7.5 验证用例清单（docs/test-cases.html）

1. 用例分四组：通用（截图 / 观感 / 窄屏）、全站通用（播放器与参数系统）、原语页（8 页各 6–9 条）、静态页；每条写明编号、作用页面、断言与通过标准、状态。
2. 待处理区只登记不排期；变更日志只追加。
3. 附录交代验证工具与跑法。

### 7.6 面向维护者的两页

- **架构标准**（docs/architecture.html）：需求模型、组件清单、代码分层与页面依赖、运行时时间轴、扩展点。
- **规范清单**（docs/specs.html）：全部规范文件的责任表与体系关系图。

## 8. 质量与验收

1. **一切可判定**：每个功能行为都有能判「过 / 不过」的编号用例（当前 110 条），清单唯一来源是 `docs/test-cases.html`；改验证规则先改清单页。
2. **全站共享能力**（播放器、参数、聚焦、解说、导航、窄屏重排）的用例必须在 8 个原语页**全部**通过——单页通过不算数。
3. **四帧截图互不相同**（初始 / 飞行中点 / 终态 / 窄屏）——字节数完全相同即废帧。
4. **窄屏不溢出**：无横向滚动、无文字截断、卡片不重叠。
5. **无假通过**：页面挂载失败必须能被识别，不得静默当作通过。
6. **终态即对照表**：动画终态以前后对照表为准逐格一致。
7. **解说对账**：steps.html 手写稿与实际动画的步数、行数、总秒、每行起止逐行一致（±5ms），作为手写稿漂移的主闸门。
8. **时序完备**：相邻步骤首尾相接、无空档无重叠，末步结束点即总时长；调整任一耗时后仍成立。
