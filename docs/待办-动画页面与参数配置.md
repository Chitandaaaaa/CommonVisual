## ① All-Reduce / Reduce-Scatter / All-to-All 三个动画页面需要调整

这三个页面的**多数据落位没有给「错峰」留出时间**，表现为「上一批还没落完，下一趟就出发」。

`seatGap` 默认改成 0.5s 之后，四块一批要 `3 × 0.5 = 1.5s` 才落完，而下一趟出发更早（实测，单位秒）：

| 页面 | 第一批落位时刻 | 下一趟出发 | 重叠 |
|---|---|---|---|
| all-reduce | 2.66 / 3.16 / **3.66 / 4.16** | 3.20 | ≈ 1.5s |
| reduce-scatter | 2.10 / 2.60 / **3.10 / 3.60** | 3.26 | ≈ 0.9s |
| all-gather（参照） | 3.50 / 4.00 / **4.52 / 5.02** | 5.12 | ≈ 0.45s |
| all-to-all（参照） | 1.86 / 2.36 / 2.86 / **3.36** | 3.70 | ≈ 0.2s |

**为什么前两个必须修**：all-reduce 与 reduce-scatter 是 recursive doubling / halving，
**第二轮依赖第一轮的结果**。现在画面上第二轮的包出发时，第一轮的段还没落完 ——
观众会读成「结果还没出来就开始下一轮交换」，语义是错的。
（all-to-all 每一步各发各的那片，不依赖上一步，重叠 0.2s 可以不管。）

**当前决定：先接受，不动时间轴**（用户 2026-10-29 确认）。要修时的两条路：

- **A. 给错峰让位**（推荐）：把落位时段加长到装得下 `(块数−1) × seatGap`。
  all-reduce 的 `TM.merge` 由 0.65 提到 1.5、reduce-scatter 的 `TM.pop` 由 0.6 提到 1.5
  （并把 `TM.gap` 提到 0.6 容纳弹跳尾巴）、all-gather 每轮「间隔」由 1s 提到 1.5s。
  代价：这三页总时长各 +1.5~2s（5.55→≈7.25 / 5.6→≈7.5 / 13.95→≈15.45）。
  all-gather 需要 `primitive.js` 的 `SEAT_PARTS` 支持每段覆盖 `hold`，现在还不支持。
- **B. 调小 seatGap**：会让「一个一个落」的观感变弱，属于退让，不建议优先。

除重叠之外，这三个页面还没有逐页过一遍观感（卡片/连线/徽章在窄屏上的表现、字幕断句），
排期时一起看。

## ② 这三个页面右上角的「时序」配置还没接

目前只有 **gather** 真正调用了 `CV.gear()`；`scatter.html` 引了 `assets/cv/gear.js`
但 `scatter.js` 里没调用（半成品）。剩下 **all-reduce / reduce-scatter / all-to-all /
broadcast / all-gather / scatter** 六个页面都没有面板。

接法（照 gather）：

1. HTML 里按顺序加三个脚本（`pages.js` 必须在 `primitive.js` 之前，`tokens.js` 在 `kit.js` 之前）：

   ```html
   <script src="assets/cv/tokens.js"></script>
   <script src="assets/cv/pages.js"></script>
   <script src="assets/cv/gear.js"></script>
   ```

2. `CV.primitive({...})` 之后调用：

   ```js
   CV.gear({ page: 'allreduce', name: 'All-Reduce', getCh: ..., onChange: ... });
   ```

3. 每个页面要暴露「重算时间轴」的入口（`getCh()` / `onChange()`），
   否则改完数字控件和进度条不会重排 —— 这一步是这几个页面还没接的真正工作量。

## ③ 规范页的动画关键配置还没补完

参数调试台现在只有三组，**组件规范里还有大量动效参数是写死在代码里的**：

| 已有 | 章节 | 参数 |
|---|---|---|
| ✅ | 03 卡片动态（一排↔两排） | `cardDur` `blockDur` `blockGap` |
| ✅ | 05 数据包 | `packDur` `packFade` `packLead` `trailDist` `trailScale` |
| ✅ | 08 落位弹跳 | `popDur` `seatGap` |
| ✅ | 09 融合 | `fuseDur` `mergeGap` `fuseWake` `fuseRise` `fuseFade` `fuseSwap` `fuseShrink` `fuseGloss` `fuseTrail` |

待补（按优先级）：

- **聚焦 `CV.attachFocus`**（03/04 附近的聚焦态）—— 高亮描边、压暗其它卡、过渡时长，目前全是 CSS 常量。
- **卡片与徽章**：徽章数字变化时的处理、`badge` 缩放。
- **连线（wire）**：激活态描边宽度、虚线节奏、流动速度。
- **字幕 / 进度条**：属于页面控件，不进组件规范（保持现状）。

补一个参数的固定动作：
① `kit.js` 的 `SCHEMA` 加一项（含 `label / unit / def / min / max / step`，按需给 `groups` 分组）→
② 该动效的实现改成每帧读 `CV.params.get(section, key)`（**不要**只在初始化时读一次，
否则拖滑杆没反应）→ ③ `tokens.js` 补默认值 → ④ 规范页对应小节的说明文字做成函数，
跟着 `CV.params.onChange` 重渲染（写死的数字会变成假文档）→ ⑤ README 的参数清单同步。
