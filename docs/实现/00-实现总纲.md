## 2. 核心架构决策（一条）：纯函数时间轴

**一切画面状态都是 t 的纯函数。**

```
scenes(纯数据) ─┐
facts(②转录)  ─┼→ compile ─→ 时间轴 { steps, events, tweens, gear, total }
spec(④转录)   ─┘                │
                    ┌────────────┴────────────┐
                director(逐帧采样)        narrate(解说行)
                    │                          │
                 parts(零件句柄)            chrome(齿轮面板)
```

- **events**：瞬时状态变更（槽变块、线点亮…），渲染 = 基态 + 顺放 ≤t 的事件。
- **tweens**：连续量（飞行位置、透明度、缩放、卡高），渲染 = 按 t 采样。
- 组件（parts）不持定时器、不自组合，只有「被设值」的句柄——⑦的播放/seek/循环只是换 t 的推进方式。
- 解说行与动画**同源**：compile 在构造相的同时按⑤句式产出行，天然对齐，闭合断言内置。

```
src/
├── index.html                  导航页（8 页入口）
├── <primitive>.html ×8         薄壳：脚本清单 + CV.boot('<id>')
├── assets/
│   ├── spec.js                 ④转录：参数表 + CV.spec()（表外键抛错）
│   ├── facts.js                ②转录：pre/post/verbs/轮次/边/锚点
│   ├── lexicon.js              ⑤转录：23 动作词 + 卡名/句式助手
│   ├── curves.js               ③：弹跳曲线（唯一一份）+ 飞行缓动
│   ├── geom.js                 ③：版式坐标公式 + S 形弧线 + 车道偏移
│   ├── parts/
│   │   ├── card.js             ③：rank 卡（标题条/角标/槽位排/长高/计算层）
│   │   ├── wire.js             ③：连线五态画笔 + 箭头
│   │   └── packet.js           ③：数据包 + 两层残影
│   ├── engine/
│   │   ├── compile.js          ⑥：相目录展开 → 时间轴（五种页型构造器）
│   │   ├── narrate.js          ⑤⑥：行生成 + 闭合断言（抛错即构建失败）
│   │   └── director.js         ⑦：挂载/播放/seek/循环/悬停聚焦 + CV.boot
│   ├── chrome.js               ⑦：齿轮面板三页签 + 高亮跟随
│   ├── stage.css               舞台样式（只读 var(--cv-*)）
│   └── scenes/
│       └── <id>.js ×8          ⑥：纯数据剧本（版面/连线/流/静止行）
└── dev/

```

| 模块 | 职责 | 边界（不管） | 治理 | 消费 | 被消费 |
|---|---|---|---|---|---|
| spec.js | 键值字典 | 任何行为 | ④ | —— | 全部 |
| facts.js | 通信事实 | 动画 | ② | spec | compile |
| lexicon.js | 词与名字 | 时刻 | ⑤ | facts(卡名) | compile/chrome |
| curves.js | 曲线采样 | 何时用 | ③ | spec | parts/compile |
| geom.js | 几何公式 | 状态 | ③ | spec | parts/compile |
| parts/* | 零件句柄 | 时间、原语 | ③ | geom/curves/spec | director |
| engine/compile.js | 相→时间轴 | 绘制 | ⑥ | spec/facts/lexicon/geom | director/narrate/chrome |
| engine/narrate.js | 行+断言 | 绘制 | ⑤⑥ | compile/lexicon | chrome |
| engine/director.js | t 的分发 | 内容真值 | ⑦ | compile/parts | chrome |
| chrome.js | 面板行为 | 时序真值 | ⑦ | compile/narrate/spec | —— |
| scenes/* | 页面数据 | 行为 | ⑥ | —— | compile |

## 4. 依赖方向（单向，违者即架构缺陷）

```
chrome → director → parts → geom/curves → spec
             └→ compile → scenes + facts + lexicon ┘
```

- 下层不感知上层：spec 不知道谁读它；parts 不知道原语；compile 不知道 DOM。
- 平级不互引：scenes 之间零引用；pages 之间零引用。
- 共享唯一路径是下沉：两个模块都要的东西进 spec/facts/geom/lexicon，不互相 import。

## 5. 运行方式

- **看**：双击任一 `src/<primitive>.html`（file:// 可用，零构建零依赖）。
- **验**：`node src/dev/verify.mjs`——脚本内起静态服务 + 无头 Chrome（同进程，⑧防冷启动），逐页收集报错、校验闭合断言与总时长，退出码非 0 即失败。
