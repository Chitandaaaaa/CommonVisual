node tools/probe.mjs <页面> 0:"<要量的表达式>"，刻度 0 是开头、1000 是结尾；只报数、不判对错，是写新用例前的尺子。
断言写哪
tools/probes/<页面>.mjs，导出 check(pg) 返回 {name, pass, detail}；文件名与页面同名即自动配对。
写断言的速度约束
同一页的断言必须共用一次时间轴扫描：先采样一轮记下各刻度读数，再各自比对；不要每条重新 seek，否则 75 条补完会从 43 秒涨到几分钟。
报错收集
每打开一页挂一份监听（脚本崩溃 + 控制台报错/警告），换页换一份。属顺带行为，不算用例。
边界
报错为 0 不等于内容验过；挂载超过 8 秒是静默的，此时头部行 dur=null，属假通过 —— 2.1 就是为抓它而设。
