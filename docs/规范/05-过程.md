# ⑥ 过程 · 动态过程的完整定义

> 本篇定义 8 页的**动态过程**：全站相目录、顺序律、四类型、逐页相序列。它回答「何时、谁、对谁、做什么」；零件长相引③、数值引④、措辞引⑤、事实引②。
>
> 本篇是时间轴的唯一设计事实。实现（scenes 剧本 → verbs 展开 → compile 编译 → narration 解说）是本篇的逐字转录；本篇所有秒数标注出处：**规范键**（随④变）或**编排秒**（1× 基线的定义本身，见①§4）。

---

## 1. 模型

- 一页 = 一条时间轴 = 相序列；相 = 齿轮「时序」页签的一行 = 解说表的一个分节。
- 时间轴只编译一次；播放 / seek / 循环只是推进方式。
- 相键体系（锚点与静止行的地址）：整页拍 `intro / open / collapse / tail`；轮内拍 `r<k><相>`（`r1fly` / `r1merge`…），轮号 1 起，与文案「第 k 轮」一致。相名单词全局唯一，同一语义不许第二个拼法。

## 3. 三轴与四类型

每一页由三根正交轴完全确定：

| 轴 | 取值（页） |
|---|---|
| 轮次结构（②） | 链式 N−1（gather/scatter/broadcast/reduce）· 环形（allgather）· 倍增互换（allreduce）· 递归减半（reducescatter）· 按目的地分步 N（alltoall） |
| 包形态 | 单体包（1 块）· 整份包（4 块）· 分片包（带下标） |
| 落位节奏（四类型） | 单传 · 连发 · 齐传 · 汇传 |

**四类型定稿**（全站落位节奏只有这四种）：

| 类型 | 页 | 落位方式 | 窗口公式 |
|---|---|---|---|
| 单传 | gather / scatter | 一块一拍，一次弹跳 | `popDur` |
| 连发 | broadcast / reduce | 整份合包一拍齐落，块间无间隔；块粒度只在「计算中」出现 | `popDur` |
| 齐传 | allgather / allreduce / reducescatter | 同轮多块同刻起弹、同刻落定 | `popDur` |
| 汇传 | alltoall | 顺序到达，第 i 块比前一块晚 `seatGap` 起跳，末块收尾＝窗口末 | `popDur + 3×seatGap` |

面板行语义：「落位弹跳」行 = **完整窗口**；分量（单颗 `popDur`、错峰 `seatGap`）全来自④，时序面板一根 k 杆整窗缩放，动画逐帧从行分量取秒。

## 4. 顺序律（全站唯一，逐条可判定）

1. **一包的一生**（串行链，一次只有一个主导相）：
   `起飞 → 飞行（packDur）→ 抵达 → 淡出（packFade）→ 落位延迟（seatDelay）→ 落位 → 弹跳（popDur）→（计算页）计算开始 → 计算中 → 计算结束`
2. **串行律**：淡出未完成不得落位；弹跳未完成不得折进；先逐块撤再收回；方框早于卡片退场；先长空间（长高）后填内容（浮现）。并行是分叉，不是风格。
3. **落位延迟全站同值** `seatDelay`：页面不许把这一拍写死进动词。
4. **预留显形是空格**：新增的第二排空位一律先显形为**空格**（灰底虚线），只有对应包在飞的那段才转接收位（紫底 `···`）。
5. **长高顶边钉死**：卡片长高一律顶边钉死、只往下长；标题条不动。
6. **收场唯一顺序**（计算页终态，全站一份）：`方框先灭（calcFade）→ 第二排逐块撤（从右往左，rowPause 间隙）→ 卡片收回单排（cardDur）→ 停驻 2s（编排秒）`。
7. **轮歇只落两轮之间**：末轮后直接进完成/收场。
8. **收窄单独一拍**：reducescatter 的收窄不与任何飞行同时。
9. **alltoall 对角线前提**：每步最多一条对角线在动，对角线才走直线中心交叉；分步规则若改，两包相撞，届时改回弧线或加法向偏移。

## 5. 传递相内动作链（单趟传递的标准相序）

一「发送数据」轮内、单趟传递的动作序列（括注 = 类型差异；同刻组内的动作同时开始）：

| 时刻 | 动作 | 时长出处 |
|---|---|---|
| t0（同刻组 1） | 交空（消耗页）/ 变暗（**仅 gather**，复制页不变暗不交空） | 瞬时 / `dimDur` |
| ↑ 同刻 | 点亮 | `wireFade` |
| ↑ 同刻 | 转接收位 | `dimDur` |
| ↑ 同刻 | 起飞（渐显 = 行程前 `takeoffFade`） | 渐显段 |
| t0 + 渐显 | 飞行（缓入缓出，两层残影） | `packDur` |
| 抵达（同刻组 2） | 抵达（瞬时）· 淡出 · 余辉（起拍，持续 `packDur×trailRatio`）· 复原（仅 gather） | `packFade` |
| 淡出止 | 落位延迟（画面静止 · 保持接收位） | `seatDelay` |
| 延迟止 | 落位（瞬时）→ 弹跳（四类型窗口） | ③曲线 |
| 窗口止 | 轮歇 / 完成（编排秒，画面静止） | 编排秒 |

计算页在「弹跳」后插入：长高（`growDur`，顶边钉死）→ 计算框浮现（`calcFade`）→ 折进（`fuseDur`×段数，段间 `mergeGap`；与方框展示 `holdDur` 取 max）→ 框淡出止 = 折进止 + `shrinkFade × shrinkDur` → 收层（`shrinkDur`）。
