# ⑤ 文案 · 解说词的语法

> 本篇定义逐动作解说的**文本语法**：谓语词表（全集）、句式、命名规则、文本纪律。哪一步出现哪句话由⑥的相定义决定，本篇不管；词表之外的词不存在——生成器遇到表外动作直接报错。
>
> 实现转录：`assets/engine/narration.js`（`CV.NARR_LEX` + 生成器，表外动作抛错）。

承纲领：可判定 · 唯一事实。

## 1. 谓语词表（全集 23 词）

正文谓语只许出自本表。时长列为**出处**（④键名或瞬时/编排），不是数值。

| 动作 | 定义与视觉后果 | 反直觉点 | 时长出处 |
|---|---|---|---|
| 变暗 | 卡整体不透明度 → 60%，表示它正在交出数据 | 只有 gather 有；其余页用「交空」表示消耗 | `dimDur` |
| 复原 | 卡不透明度 → 100% | 在**包抵达**那一刻开始，不是落位时 | `dimDur` |
| 交空 | 送出方那一格立刻变空（1 格或 4 格同时） | 是「消耗」，不是搬走后又长回来 | 瞬时 |
| 显形 | 从不可见淡入为空格或接收位 | 显形的是「位置」，不是数据 | `revealDur` |
| 转接收位 | 空格 → 紫底 `···` | 从起飞那一刻就开始，不必等到达 | `dimDur` |
| 点亮 | 线由灰变数据色、加粗、箭头换色；飞行期间虚线随包前进 | 颜色是渐变过去的 | `wireFade` |
| 起飞 | 包在起点出现并渐显 | 渐显只占行程前 `takeoffFade` 比例 | 渐显段 |
| 飞行 | 包沿路径前进，缓入缓出，两层残影跟随 | 不是匀速 | `packDur` |
| 抵达 | 包停在箭头尖 / 终点，位置不再变化 | —— | 瞬时 |
| 淡出 | 包不透明度线性 → 0 | 包是被目标「吃进去」；完成后才轮到落位 | `packFade` |
| 余辉 | 线降到 glow 态保留数据色 | **不是变灰**；持续 = `packDur × trailRatio` | 瞬时（起拍） |
| 落位 | 接收位消失，该槽当场变成数据块 | **不是渐变换色** | 瞬时 |
| 弹跳 | 该槽 35% → 116% → 100%（③曲线） | 多块**两口径**：齐弹（broadcast / reduce / allgather / allreduce / reducescatter）、错峰（alltoall）——窗口公式在⑥ | `popDur`（+`seatGap`） |
| 长高 | 卡高增加一层，顶边钉死、只往下长 | 腾第二排 `cardDur`，腾计算层 `growDur`；开场只做一次，收场才收回 | `cardDur` / `growDur` |
| 逐块出现 | 第二排的接收位从左到右一块块淡入 | 是「位置」逐个出现 | `blockDur`/块，隔 `blockGap` |
| 逐块撤 | 第二排的接收位从右往左一块块撤掉 | 先撤块，再收卡，不能同时 | `blockDur`/块，隔 `blockGap` |
| 计算框·浮现 | 卡中间写 `sum · avg · max · min` 的方框淡入 | 先长空间，后填内容 | `calcFade` |
| 计算框·淡出 | 方框淡出，卡片随后缩回 | 方框一定早于卡片退场 | `calcFade` |
| 折进 | 下排的块被吸进上排累加器，上排块变 Σ、份数 +1（all-reduce 翻倍） | 不是复制过去 | `fuseDur`/段，段间 `mergeGap` |
| 收层 | 计算态卡退回双排卡：方框先灭（`calcFade`）、卡片再缩回（`shrinkDur`），两相串行 | 只剩卡片在缩，数据钉在原地 | `shrinkDur` |
| 收回 | 收场时卡片从双排退回单排 | 先逐块撤、再收回，不能同时 | `cardDur` |
| 收窄 | reducescatter 第二轮前，把这一轮用不上的一格撤掉 | 单独一拍，不跟飞行同时发生 | `blockDur` |
| 静止 | 整段画面无运动对象 | 单独成一节，也参与高亮 | 按步 |

## 2. 句式

1. 一行 = `主体 · 动作（补充）`；**结果列只放对象**（落到哪、变成什么），不写完整句。
2. 复合动作写 `A → B`（如「计算框 · 淡出 → 收层」）——每一段都必须在词表里。
3. 主体写卡名/槽名/线名/包名/「画面」；「画面 · 静止」是静止行的固定主体。
4. 补充括注只写主体修饰（「（4 格）」「（齐弹）」「（从右往左）」），不写秒数。

## 3. 卡名写法

格式：`卡形态[-槽号]`；同一版面有多张同形态卡时加 `r<rank>/` 前缀。

| 写法 | 含义 | 用于 |
|---|---|---|
| `四槽卡-2` | 四槽卡的第 2 槽（版面里只有一张四槽卡时） | gather / scatter / broadcast / reduce 的 rank 0 |
| `r1/四槽卡-3` | 2×2 版面里 rank 1 那张的第 3 槽 | reduce 家族四页 |
| `r2/单槽卡` | 单槽卡只有 1 槽，不写槽号，用 rank 区分 | gather/scatter/broadcast 的右侧三张 |
| `四槽卡` | 整张卡作主体（不指槽），只写形态名 | 如「四槽卡 · 长高」 |

## 4. 静止行

- 固定写法 `画面 · 静止`，结果列写**此刻场上有什么**。
- 静止行文案的唯一出处是各页 scene 的 `narr.rest`（键 = 相键，见⑥相键体系）；文档与面板都只读它。
- 静止行参与高亮：播到静止段，画面无动作、列表高亮静止行，自洽。

## 5. 文本纪律（可判定）

1. **禁嵌时间值与参数插值**：时间值只活在「开始 / 结束」两列（随参数重算）；解说列与结果列不嵌任何秒数、不做参数插值。参数改动后解说文本必须一字不变——文本变了就是把可变值焊死进了文案。
2. **节奏用词表达**：同刻说「同时」，分相说「错峰」，落差不写数。
3. **表外词即错**：谓语不在 §1 表内 → 生成器抛错；想加动作先补本表。
4. **秒数从编译产物现取**：任何展示场合（面板/文档视图）的秒数只能从时间轴现算，禁止手写。
