# ⑦ 呈现 · 界面行为

> 本篇定义过程之外的**界面行为**：播放器怎么推进时间、齿轮面板怎么展示与调整、聚焦与响应式怎么响应。它只展示⑥的过程、只调④的参数，不改变过程本身的时序。
>
> 实现转录：`assets/engine/director.js`（挂载与逐帧分发）+ `assets/parts/chrome.js`（齿轮面板）。

---

## 1. 播放器

| 行为 | 规范 |
|---|---|
| 播放 / 暂停 | 唯一差别是 t 的推进方式；不重编译时间轴 |
| seek | 参数 0–1（归一化）；UI 刻度条用 0–1000 整数 scrub，换算交给页面 `getCh()`，**禁止把 0–1000 直接喂给 seek**（会被钳成终态） |
| 循环 | 到尾回卷继续，时间轴不变 |
| 播放速度 | ④ `pageSpeed`；编译期整轴同除，解说区间跟变、文案不变 |
| 时长 | 面板显示秒数 = 编译产物 `total ÷ pageSpeed`，现取不手写 |

## 2. 响应式与聚焦

- **断点 860px**：以下用窄屏骨架（④ `nr*` 组），以上用桌面骨架（`dt*` 组）；resize 防抖切换，两套几何同一剧本。
- **悬停聚焦**：悬停数据块时保留目的地卡 + 该数据所在源卡（各页 scene 的 `keepCards`），其余卡降透明；焦点切换即时刷新，不改时序。
- **无障碍**：每页一个 aria 标签，描述本页通信过程（如 gather：「rank 1、2、3 的数据依次汇入 rank 0」）。

## 3. 齿轮面板

入口：舞台右下角齿轮按钮，点开右侧浮层面板，宽 660px（五列排得开、字号可读）；滚动条只在内层列表，头部与标签条固定。

三个页签：**时序**（默认）· **逐动作解说** · **外观**。

### 3.1 时序页签

- 一行 = ⑥相目录的一个相；组头「发送数据 ×N」= 组内各行按轮数共用（组头行号范围 = 组内行挂的进度条段）。
- 规范行（挂④键的行）给 k 倍数杆：规范改了全站跟、杆改了本行变；自定义行直接填秒。
- 覆盖持久化在 `cv.cfg.page.v1`（页名为键，单键全页合一）。
- 行名全集以⑥相目录为准，面板不得出现目录外的行名。

### 3.2 逐动作解说页签

- 数据源 = 引擎解说生成器（narration）的实时输出，五行列结构：

| 列 | 宽度 | 内容 |
|---|---|---|
| 编号 | 54px | `步.节`（如 3.5） |
| 开始 | 76px | 秒，编译产物现取 |
| 结束 | 62px | 秒；**留空 = 瞬时动作** |
| 解说 | 自适应 | ⑤句式（主体 · 动作） |
| 结果 | 212px | 只放对象 |

- **同刻合并**：开始时间完全相同的连续几行共用一个「开始」格，格内标 `同刻 ×N`；高亮时这几行一起亮。
- 分节头行 = ⑥的相（「第 3 步 · B 传递」+ 区间 `1.20 → 5.35`），区间随参数重算。
- 静止行灰字样式（`画面 · 静止`）。

### 3.3 高亮与跟随（可判定）

1. 当前时刻落在 `[开始, 结束)` 内 → 该行高亮；同刻几行一起亮。
2. 瞬时行（结束空）：从开始时刻起**保持高亮 0.15 秒**，否则一闪看不见。
3. 静止行照常高亮。
4. 只在「命中行集合」变化时改 class，不逐帧写 DOM。
5. 跟随播放开启时：目标行保持滚动到列表中部附近（**±20px 死区**内不滚，换行时只挪一行的高度）；用户手动滚动后**暂停跟随 2 秒**。

### 3.4 外观页签

- 全站参数调试台（按④表渲染控件）：可见、可调、可锁、可记录。
- 颜色类键出取色器；`sink:css` 的键写根变量实时生效。
- 调试台不得提供④表之外的键。

## 4. 面板边界

1. 面板只读⑥的相序列与解说、只写④的覆盖值；不得缓存第二份时序。
2. 面板行为（列宽、合并、高亮、死区）属本篇；面板里每个数字随参数重算，无手写秒。
3. 齿轮面板的字号、配色等外观细节归③组件状态与④色板，本篇不重复。
